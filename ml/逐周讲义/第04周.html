Softmax与基线：正式启动手写数字项目

01多分类需要每类一个分数

识别0到9需要10个互斥类别。不能让10个独立sigmoid概率各自随意变化再声称它们构成一个类别分布，因为总和可能不为1。softmax为每类给一个logit，再把指数归一化，使同一样本的各类概率和为1。若一个样本可同时有多个标签，问题变成多标签分类，常用独立sigmoid；先明确任务结构，才选择输出层。

假设批量X形状(n,d)，权重W形状(d,K)，偏置形状(K,)，得到logits Z形状(n,K)。每一行对应一个样本，softmax沿类别维度做；若沿样本维度归一化，就会让一个样本的概率依赖同批其他样本，语义错误。把偏置加入常数列时，W变成(d+1,K)，逻辑仍相同。

标签可以用整数数组y，形状(n,)，也可用one-hot矩阵Y，形状(n,K)。整数标签2表示第2号类，不表示它是类别1的两倍；one-hot只在真实类处为1，其余为0。预测类别取概率或logit的argmax，两者相同，因为指数单调且共享分母。

点击放大

同一个样本内，各类别的指数分数归一化。

逐个认识符号

  • i：样本编号；k或c：类别编号

  • K：类别总数；z_ik：第i个样本的第k个logit

  • p_ik：该样本属于类别k的概率估计

一起算一个例子

三个类别的概率

  1. 取logits=(0,ln2,ln3)，指数为(1,2,3)，分母为6。

  2. 概率为(1/6,1/3,1/2)，总和1，预测类别2（代码从0编号）。

  3. 若真实类为1，真实类概率是1/3，交叉熵为-log(1/3)=ln3≈1.098612。

交叉熵只读取真实类别概率，但所有logit通过分母彼此影响。

02平移不变性、稳定计算与梯度

给同一行的全部logit加上相同常数，分子分母都乘同一个指数因子，概率不变。利用这一点先减去行内最大值，至少有一项指数为1，其余不超过1，避免exp(1000)溢出。不是把最大logit直接置零而保持其他项不变；必须整行一起减。

多分类交叉熵对每个logit的导数是p_k-Y_k。真实类对应p-1，其他类对应p。各分量之和为0，与整体平移不改变损失吻合。再乘输入特征、跨样本平均，得到W的梯度。本周循环版故意不隐藏这几个维度，后面改成矩阵式X.T@(P-Y)/n时会更容易理解。

不要为了数值安全随意把概率截断后仍声称完全相同的目标函数。训练损失可直接用log-sum-exp：最大值加上移位后指数和的对数，再减真实类logit。示例就是这样算损失；标签不经过softmax，one-hot只是用于表达目标。

点击放大

多分类交叉熵等于log-sum-exp减去真实类别分数。

逐个认识符号

  • ell_i：样本i的损失；y_i：真实类别编号

  • z_i,y_i：真实类别对应的logit

点击放大

对所有类别的梯度一起更新，而不只更新赢家。

逐个认识符号

  • Y_ik：one-hot目标，真实类为1，其他类为0

  • p_ik：softmax概率

稳定softmax与一次更新

  1. logits=(1000,1001,1002)，减最大值得(-2,-1,0)，概率约(0.090031,0.244728,0.665241)。

  2. 真实类为1时，三个logit梯度约(0.090031,-0.755272,0.665241)，和约0。

05代码桥梁：嵌套容器与argmax

Python的[[0.]*3 for _ in range(3)]每轮创建不同内层列表；[[0.]*3]*3会重复引用同一行，改一个权重可能连其他行一起变。sum(row[j]*w[j][k] for j in range(3))是固定类别k后沿特征j求和。max(range(3),key=lambda k:z[k])返回分数最大的类别编号，而不是最大分数本身。

C++用array<Row,3>保存二维权重，{}将数值初始化为0。lambda中的[&]使logits读取当前w；softmax按值接收Row，因此对临时分数的归一化不修改模型权重。表达式(k==y[i])的布尔值用于算术时变成0或1。C++显式循环选最大值，遇相等保留较小编号，和Python本例规则一致。

Python

"""Week 04: three-class softmax; CPU; Python standard library."""
# STEP 1: Rows are samples, columns are features; final 1 is an intercept.
import math
x = [(1., 0., 1.), (0., 1., 1.), (-1., -1., 1.)]
y = [0, 1, 2]
w = [[0.] * 3 for _ in range(3)]
# STEP 2: Subtracting the row maximum preserves probabilities.
def softmax(z):
    maximum = max(z)
    exp_z = [math.exp(v - maximum) for v in z]
    return [v / sum(exp_z) for v in exp_z]
def logits(row):
    return [sum(row[j] * w[j][k] for j in range(3)) for k in range(3)]
print("stable=" + ",".join(f"{v:.6f}" for v in softmax([1000.,1001.,1002.])))
# STEP 3: A full batch accumulates the mean gradient before updating.
for step in range(200):
    g = [[0.] * 3 for _ in range(3)]
    for row, target in zip(x, y):
        p = softmax(logits(row))
        for j in range(3):
            for k in range(3):
                g[j][k] += row[j] * (p[k] - int(k == target)) / len(x)
    for j in range(3):
        for k in range(3):
            w[j][k] -= 0.2 * g[j][k]
# STEP 4: Evaluate log-loss stably from logits, not rounded probabilities.
loss, correct = 0., 0
for row, target in zip(x, y):
    z = logits(row)
    m = max(z)
    loss += m + math.log(sum(math.exp(v-m) for v in z)) - z[target]
    correct += max(range(3), key=lambda k: z[k]) == target
print(f"training_loss={loss / len(x):.6f} training_accuracy={correct / len(x):.6f}")
# STEP 5: A declared tie rule makes this majority baseline reproducible.
counts = [y.count(k) for k in range(3)]
majority = max(range(3), key=lambda k: counts[k])
print(f"majority_class={majority} majority_accuracy={counts[majority]/len(y):.6f}")
print("scope=three-point mechanism; not digits project results")

C++

// Week 04: C++17 three-class mechanism, not a digits benchmark.
#include <algorithm>
#include <array>
#include <cmath>
#include <iomanip>
#include <iostream>
using Row = std::array<double, 3>;
// STEP 1: Three features include the constant intercept feature.
int main() {
    std::array<Row,3> x{{{{1,0,1}},{{0,1,1}},{{-1,-1,1}}}};
    std::array<int,3> y{{0,1,2}};
    std::array<Row,3> w{};
    // STEP 2: The normalization is over classes for ONE sample.
    auto softmax = [](Row z) {
        double maximum = std::max(z[0], std::max(z[1], z[2]));
        double denominator = 0;
        for (double& v : z) { v = std::exp(v-maximum); denominator += v; }
        for (double& v : z) v /= denominator;
        return z;
    };
    auto logits = [&](const Row& row) {
        Row z{};
        for (int j=0;j<3;++j) for (int k=0;k<3;++k) z[k]+=row[j]*w[j][k];
        return z;
    };
    Row stable = softmax({{1000,1001,1002}});
    std::cout << std::fixed << std::setprecision(6)
              << "stable=" << stable[0] << "," << stable[1] << "," << stable[2] << "\n";
    // STEP 3: g is reset every update; w is changed after the sample loop.
    for (int step=0;step<200;++step) {
        std::array<Row,3> g{};
        for (int i=0;i<3;++i) {
            Row p=softmax(logits(x[i]));
            for (int j=0;j<3;++j) for (int k=0;k<3;++k)
                g[j][k]+=x[i][j]*(p[k]-(k==y[i]))/3;
        }
        for (int j=0;j<3;++j) for (int k=0;k<3;++k) w[j][k]-=.2*g[j][k];
    }
    // STEP 4: log-sum-exp computes cross-entropy without log(0).
    double loss=0; int correct=0;
    for (int i=0;i<3;++i) {
        Row z=logits(x[i]); int predicted=0;
        for (int k=1;k<3;++k) if (z[k]>z[predicted]) predicted=k;
        double m=z[predicted], total=0;
        for (double v:z) total+=std::exp(v-m);
        loss+=m+std::log(total)-z[y[i]];
        correct+=predicted==y[i];
    }
    std::cout<<"training_loss="<<loss/3<<" training_accuracy="<<correct/3.0<<"\n";
    // STEP 5: Equal counts choose the lowest class index.
    std::cout<<"majority_class=0 majority_accuracy="<<1.0/3<<"\n";
    std::cout<<"scope=three-point mechanism; not digits project results\n";
}

逐步解释

明确两个轴

三行是样本，三列输入包含两个特征和偏置。W[j][k]表示输入j通向类别k的权重。Python嵌套列表须逐行新建，不能用会共享内层列表的写法。

自查：画出W的行列语义。

行内稳定概率

先求每行logits，再减该行max。C++的lambda通过捕获w读取当前参数，softmax只接收该样本的三个分数。

自查：整行加1000后概率是否应变？

累积整批梯度

每步清零g；样本、特征、类别三层循环累加x*(p-one_hot)/n；完整批量结束后才更新w。bool转0或1对应one-hot。

自查：真实类别那一项为什么减1？

稳定损失与准确率

交叉熵用log-sum-exp，准确率用argmax。两者度量不同，准确率不变时损失仍可能下降。

开放讲解题

准确率没变，交叉熵为什么仍会下降？

argmax保持不变即可使类别不变，但模型仍能把更多概率给真实类别。例如真实类概率从0.6升到0.8，两次都分对，负对数损失却降低。
