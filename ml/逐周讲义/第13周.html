把图像变成序列：自回归、偏移目标与RNN

011 下一像素预测为什么也是序列问题

一张20×20离散颜色图可以按行读取，变成400个颜色ID。token在这里就是一个颜色编号，而不是汉字或单词。若颜色表有167项，ID范围是0到166。先约定扫描顺序与颜色映射，再验证展平后能原样还原；否则模型可能在学习错误的空间顺序。

概率链式法则把整条序列的联合概率拆成条件概率的乘积。预测第t个token时，只能使用之前的token。取负对数把乘积变成可加的损失，因此下一token交叉熵可以逐位置求和。没有BOS时，常见实现用第1到399像素预测第2到400像素，第一像素概率不在这个计分目标中，报告必须说明计分位置。

连续颜色RGB值与离散颜色ID不是同一建模接口。ID=10并不天然比ID=9更接近，不能当作一个有序数值回归目标。嵌入层以ID查表得到一个可学习向量，类似一个索引访问一行参数。表中不同颜色的关系通过训练形成；像素位置另由扫描顺序和后续位置表示传达。

项目B沿用HW4：随机初始化的小GPT2式像素模型、20×20图、167种颜色。它没有语言预训练知识。数据来自作业指定Hugging Face数据集，本地notebook本身并不包含完整训练数据。开始前检查版本、实际数量和重复图，再按完整原图分组划分，不能把同图裁片或变色版本拆进不同集合。

022 teacher forcing、频率基线与评估单位

训练时把真实前缀输入模型，让各个位置预测下一个真实token，这叫teacher forcing。若网络有正确因果遮罩，整条真实输入可以一次并行计算多个位置，因为每个位置依然只能访问自己的过去。生成时没有未来真实token，只能把模型刚生成的token接回输入，错误可能逐步积累。

先做一个不看上下文的颜色频率基线：仅统计训练集计分位置中各颜色出现次数，加一个平滑伪计数再归一化。它容易实现，也能发现损失单位和目标偏移错误。某种颜色没有在训练中出现时，加平滑避免预测概率为0导致无限logloss。平滑值是事先规定的超参数，不能看测试集后随意选。

本例两个训练序列分别[0,1,1,2]与[0,1,2,2]，只统计后3个位置，颜色0、1、2计数为0、3、3；每类加1后为1、4、4，总数9。验证序列[0,2,1,2]的目标都在颜色1和2之间，所以平均损失为−ln(4/9)。注意训练集第一位置全是0，但它不在本例预测目标中，不能混进统计再声称比较完全相同。

短长序列混合时，先按有效预测token数累计损失；若按图像先平均再等权求均值，定义会不同。若使用padding，必须明确忽略哪些位置。比较模型和基线要有同一词表、同一计分位置、同一对数底数，不能把总损失与平均损失直接相减。

033 RNN如何把过去压进状态

RNN维护一个隐藏状态h_t。每读一个token，把其嵌入向量与上一步状态组合，再经过非线性。状态是“到当前位置为止”的压缩表示，不是把过去所有token原封不动存下来。本页先用一维状态，把矩阵乘法缩为数乘，逐步看清时间方向。

令嵌入表[-1,0,1]，状态递推h_t=tanh(0.5h_(t−1)+e(x_t))，初始状态0。前向时只依赖此前状态，所以改变最后一个输入不会影响更早的状态。程序将这个不变量写成断言。RNN训练时还要通过时间展开反传，多个时间步重复乘局部导数可能带来梯度消失或爆炸；本周不要求手写完整BPTT。

RNN的串行依赖说明为什么长序列训练不容易并行。下周注意力直接让一个位置按权重读取此前各位置的表示，但这不意味着忘记序列顺序。RNN和注意力都可以做条件概率建模，差别在上下文的表示与读取方式，而不是只有其中一个才叫自回归。

一起算一个例子

读三个token的状态

  1. 输入[0,2,1]，嵌入分别−1、1、0。

  2. h₁=tanh(−1)≈−0.761594。

  3. h₂=tanh(0.5×h₁+1)≈0.550573。

  4. h₃=tanh(0.5×h₂+0)≈0.268537。

第三token改动只能改变第三及以后状态，不能改变前两步。

Python与C++机制示例

下面的小程序验证关键机制；完整项目须按本周交付要求另行完成。

Python

"""Token shift, a smoothed training-only baseline, and scalar RNN states."""
import math
# STEP 1
train = [[0,1,1,2],[0,1,2,2]]
valid = [0,2,1,2]
vocab = 3
counts = [1.]*vocab  # Laplace pseudocounts
for row in train:
    for token in row[1:]:
        counts[token] += 1
prob = [c/sum(counts) for c in counts]
# STEP 2
inputs, targets = valid[:-1], valid[1:]
nll = -sum(math.log(prob[t]) for t in targets)/len(targets)
print('inputs='+' '.join(map(str,inputs)))
print('targets='+' '.join(map(str,targets)))
print('baseline_prob='+' '.join(f'{p:.6f}' for p in prob))
print(f'valid_nll={nll:.6f}')
# STEP 3
embedding = [-1.,0.,1.]
def rnn(tokens):
    h, states = 0., []
    for token in tokens:
        h = math.tanh(.5*h+embedding[token])
        states.append(h)
    return states
states = rnn(inputs)
print('rnn_states='+' '.join(f'{h:.6f}' for h in states))
# STEP 4
changed = inputs.copy()
changed[-1] = (changed[-1]+1)%vocab
assert states[:-1] == rnn(changed)[:-1]
assert inputs[1:] == targets[:-1]
print('shift_and_prefix_check=True')

C++

#include <vector>
#include <array>
#include <cmath>
#include <iostream>
#include <iomanip>
#include <cassert>
// STEP 1
std::vector<double> baseline(const std::vector<std::vector<int>>& train) {
    std::vector<double> p(3,1.);
    for(const auto& row:train) for(std::size_t i=1;i<row.size();++i) ++p[row[i]];
    double total=0; for(double c:p) total+=c;
    for(auto& v:p) v/=total;
    return p;
}
int main() {
    std::vector<std::vector<int>> train{{0,1,1,2},{0,1,2,2}};
    std::vector<int> valid{0,2,1,2};
    auto prob=baseline(train);
    // STEP 2
    std::vector<int> inputs(valid.begin(),valid.end()-1),targets(valid.begin()+1,valid.end());
    double nll=0; for(int t:targets) nll-=std::log(prob[t])/targets.size();
    std::cout<<std::fixed<<std::setprecision(6)<<"inputs=";
    for(std::size_t i=0;i<inputs.size();++i) std::cout<<(i?" ":"")<<inputs[i];
    std::cout<<"\ntargets=";
    for(std::size_t i=0;i<targets.size();++i) std::cout<<(i?" ":"")<<targets[i];
    std::cout<<"\nbaseline_prob=";
    for(int i=0;i<3;++i) std::cout<<(i?" ":"")<<prob[i];
    std::cout<<"\nvalid_nll="<<nll<<'\n';
    // STEP 3
    auto rnn=[](const std::vector<int>& tokens) {
        const std::array<double,3> emb{-1,0,1}; double h=0; std::vector<double> states;
        for(int token:tokens) {h=std::tanh(.5*h+emb[token]);states.push_back(h);}
        return states;
    };
    auto states=rnn(inputs);
    std::cout<<"rnn_states=";
    for(std::size_t i=0;i<states.size();++i) std::cout<<(i?" ":"")<<states[i];
    // STEP 4
    auto changed=inputs; changed.back()=(changed.back()+1)%3;
    auto altered=rnn(changed);
    for(std::size_t i=0;i+1<states.size();++i) assert(states[i]==altered[i]);
    for(std::size_t i=1;i<inputs.size();++i) assert(inputs[i]==targets[i-1]);
    std::cout<<"\nshift_and_prefix_check=True\n";
}

逐步解释

训练集内计数

Pythoncounts初始化为3个1，C++baseline同样添加伪计数；两者从每行索引1开始统计，避免混入未计分首token。

自查：解释总数为何是9而非8或12。

偏移与评分

切片或迭代器范围分别构造前3个输入和后3个目标，用目标索引读取基线概率。log是自然对数，最后按目标长度平均。

自查：手算valid_nll≈0.810930。

循环状态

embedding按颜色ID索引，h先读旧值再写新值，每一步保存到states。C++lambda只是局部函数，不自动求导。

自查：用计算器复算第二步，说明0.5乘的是哪一个状态。

前缀不变量

复制输入后只改最后token，重新前向，比较早期状态；同时检查输入从第二项起和目标去末项一致。

自查：给一个偏移两次的错误例子，说明该断言能发现什么、不能发现什么。

开放讲解题

为什么语言建模与像素建模可共用下一token损失？

两者都可以把对象表示成离散序列并按条件概率链分解。共同的是概率形式和训练接口；词表含义、空间结构、数据规模和评价目标不同，因此小像素模型不是语言大模型。

低teacher-forced损失为什么不保证补全好看？

评分时使用真实前缀，生成时使用自己产生的前缀；误差会改变后续上下文。平均逐token损失也不直接等价于整体结构、语义或视觉美观，需要独立生成展示及失败分析。
