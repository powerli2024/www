正则化与学习曲线：让错误有可检验的解释

01训练成绩好，为什么仍可能学得不好

模型容量表示它能表达多少种关系。直线无法拟合明显弯曲规律，可能训练与验证误差都高；高阶曲线可以追随训练噪声，训练误差低而验证误差高。但这只是常见现象，不是看到曲线就自动得到诊断。若实现有错、学习率不合适、训练还没完成，也可能两边误差都高。

偏差描述对许多训练集重复学习后的平均预测与真实规律之间的系统差异；方差描述这些训练集改变时预测的波动。一个给定模型在一份训练集上“误差大”不等于已经估计了偏差，两个种子给出不同结果也不能直接等同于完整统计方差。概念需要区分随机数据、训练随机性与模型形式。

在平方损失、y=f(x)+噪声、噪声条件均值为0等假设下，可以把某个x处的期望预测误差分解为偏差平方、方差和不可约噪声。它帮助提出假设，但有限实验常常只能观察部分迹象。本周重点是设计能区分解释的实验，不要求用一张图反推出不可观测的真值。

02L2正则把偏好写进目标函数

线性回归的MSE只要求拟合训练标签。L2正则再加入权重平方和，表达“在拟合相近时更偏好较小权重”。lambda越大，偏好越强。一般对权重惩罚而不惩罚偏置，因为整体均值不应与特征斜率承担完全相同约束；本页手算使用中心化数据和零截距，避免把两者混淆。

对lambdaw²求导得到2lambdaw，所以更新中多了一个朝零拉回的项。它不是删除大权重，而是连续收缩。特征量纲会改变权重大小，因此正则与标准化密切相关：同样预测关系换单位后，若不调整惩罚就等于改变了模型偏好。Scaler必须仍然只fit训练部分。

验证时通常报告预测MSE或任务指标，而不是把训练正则项也加到验证分数里。否则不同lambda的评价规则会变，失去共同尺度。代码输出train_MSE与validation_MSE，而优化目标是MSE+lambda*w²，名字刻意区分。

03L1为何可能给出精确的零

L1惩罚使用绝对值和。离开0时，绝对值的导数是+1或-1；在0处不可微，需要用次梯度或专门优化方法。与L2越靠近0拉力越小不同，L1在非零位置仍保留固定大小的惩罚斜率，因此某些最优系数会精确落在0。它提供稀疏性，但相关特征中选了哪一个不一定稳定。

以中心化的一维目标aw²-2cw+lambda*|w|为例，a>0。w>0时导数为2aw-2c+lambda，令其为0得到(c-lambda/2)/a；w<0同理，若|c|≤lambda/2，最优点就是0。这解释了软阈值的来源。多维特征相关时不能把各坐标简单独立套这个式子当通用解。

库的超参数命名需要核对。scikit-learn LogisticRegression中的C是正则强度的倒数方向，C越小通常约束越强；不要把“增大lambda”和“增大C”混为同一操作。不同库还可能把损失写成总和或平均，比较参数值之前先对齐约定。

L1稀疏性来自目标形状；它不是自动发现因果特征。

04用学习曲线区分数据、容量与优化问题

学习曲线有两种常被混用：横轴是训练步数的优化曲线，和横轴是训练样本数的数据学习曲线。前者看训练过程，后者要对不同训练子集重新训练。改变样本数时固定同一验证集，子集只从训练部分选取，最好使用嵌套子集并重复若干选择。不能把验证样本逐渐加入训练后还继续在它们上评分。

先做合成回归：固定真实规律、噪声和验证点，比较简单模型与高容量模型；然后改变训练样本量。若增加数据主要缩小训练验证差距，符合方差问题的解释；若两者都维持较高误差，可尝试容量或特征改进。但现实中可能有分布漂移，仍须检查验证数据是否代表使用条件。

项目A选三档C，例如0.01、1、100，在相同开发折、相同优化容差与足够迭代预算下比较。若小C表现差，可能约束过强；大C变差可能过拟合，也可能未收敛。先读警告，再看训练与验证指标。不要预设某一档必须获胜；记录所有结果和至少两个候选解释。

一起算一个例子

一次有辨别力的下一步实验

  1. 大C训练准确率高、验证略低，提出解释A：过拟合；解释B：验证样本偶然偏难。

  2. 保持开发折并改正则，若多数折差距同方向缩小，A得到更多支持。

  3. 重复合理划分、查看相同样本的错误，若改善只出现在一个折，结论需要收缩。

正则强度选择是开发过程，最终测试仍然封存。

固定真实函数f(x)=sin(πx)+0.3x，x来自[-1,1]均匀分布，标签另加标准差0.15的高斯噪声。训练随机数生成器seed=42，验证生成器seed=2026，分别生成90条训练池和2000条验证数据。训练规模取前10、前30、前90条，形成嵌套子集；小规模的样本和标签在大规模中保持原样。六个候选共用同一份独立验证集，验证数据不参与拟合。本实验没有最终测试集，结果仅用于学习与开发比较。

容量取1阶与8阶多项式。np.vander(x,N=degree+1,increasing=True)构造列[1,x,x²,…]，第一列1对应截距，参数数分别2与9；np.linalg.lstsq只用当前训练子集求最小二乘。它不是梯度下降，因此六行容量/样本量比较不会混入某个候选恰好少训练几步的差异。返回rank检查设计矩阵是否满列秩，最大/最小奇异值之比作为条件数，提醒高阶单项式可能数值敏感；满秩不等于泛化好。

按顺序操作：先预测“10条样本配9个参数”会有什么风险，再运行脚本保存全部六行train_mse与validation_mse。固定degree纵向读10→30→90，得到数据学习曲线；固定train_n横向读1阶→8阶，得到容量对照。不能把两者同时改后，将变化全部归因于数据量或容量。图中容量轴只有两个实测点，连线仅帮助比较，不代表中间阶数都已实验。

脚本另外固定n=90、degree=8，从全零系数做2000次全批量梯度下降，在0、1、10、50、100、500、2000步记录训练和同一验证MSE。这才是横轴为更新次数的优化曲线。梯度为2A.T@(A@w-y)/n；用训练矩阵计算Hessian最大特征值L=2||A||₂²/n，设置步长0.8/L以稳定这个凸二次目标。该设置是本例分析，不是所有模型的通用最佳学习率。程序核对训练MSE不增加，未要求验证MSE单调。

06代码桥梁：解析解也是可核对的程序

本周没有梯度下降循环，因为一维二次目标可以直接把导数设为0得到解。assert(abs(derivative)<...)核对一阶条件；它只在已知目标凸且曲率为正的前提下能配合推导说明是最小点。遇到一般非凸函数，导数为0还可能是极大点或鞍点。

Python函数mse通过闭包读取外层x；C++的[&]lambda读取x并按const引用接收target。两个版本都使用浮点除法，C++出现/5时分子已是double，所以不会做整数截断。把目标从平均MSE改成总平方误差，必须连ridge闭式分母和梯度一起改，不能只改输出标签。

Python

"""Week 06: ridge shrinkage, train/validation trade-off; standard library."""
# STEP 1: Centered x and y make the intercept zero in this controlled case.
x = [-2., -1., 0., 1., 2.]
train_y = [-5., -1., 0., 1., 5.]
valid_y = [2 * v for v in x]
# STEP 2: The objective is mean squared error PLUS lambda times w squared.
def mse(w, targets):
    return sum((w * a - b) ** 2 for a, b in zip(x, targets)) / len(x)
sxx = sum(a * a for a in x)
sxy = sum(a * b for a, b in zip(x, train_y))
# STEP 3: Setting the derivative to zero gives a one-dimensional ridge fit.
for regularization in (0., .2, 2.):
    w = sxy / (sxx + len(x) * regularization)
    derivative = 2 * (sxx * w - sxy) / len(x) + 2 * regularization * w
    assert abs(derivative) < 1e-12
    print(f"lambda={regularization:.1f} w={w:.6f} "
          f"train_MSE={mse(w, train_y):.6f} validation_MSE={mse(w, valid_y):.6f}")
# STEP 4: Repeated synthetic noise shows variation of fitted parameters.
estimates = []
for noise_sign in (-1, 1):
    noisy_y = [2 * v + noise_sign * n for v, n in zip(x, [-1.,1.,0.,-1.,1.])]
    cross = sum(a * b for a, b in zip(x, noisy_y))
    estimates.append((cross / sxx, cross / (sxx + len(x) * .2)))
print("two_fits_unregularized=" + ",".join(f"{a:.6f}" for a,b in estimates))
print("two_fits_regularized=" + ",".join(f"{b:.6f}" for a,b in estimates))
print("scope=two controlled noise patterns, not a statistical variance estimate")

C++

// Week 06: C++17 ridge fit and controlled perturbation.
#include <array>
#include <cmath>
#include <iomanip>
#include <iostream>
// STEP 1: All three vectors have length five and a zero mean.
int main() {
    std::array<double,5> x{{-2,-1,0,1,2}}, y{{-5,-1,0,1,5}}, valid{{-4,-2,0,2,4}};
    // STEP 2: Sum sufficient statistics and define prediction-only MSE.
    double sxx=0,sxy=0;
    for (int i=0;i<5;++i) {sxx+=x[i]*x[i];sxy+=x[i]*y[i];}
    auto mse=[&](double w,const std::array<double,5>& target){
        double total=0;
        for (int i=0;i<5;++i) total+=std::pow(w*x[i]-target[i],2);
        return total/5;
    };
    // STEP 3: The regularization coefficient multiplies a MEAN-loss objective.
    std::cout<<std::fixed;
    for (double lambda:{0.,.2,2.}) {
        double w=sxy/(sxx+5*lambda);
        double derivative=2*(sxx*w-sxy)/5+2*lambda*w;
        if (std::abs(derivative)>1e-12) return 1;
        std::cout<<std::setprecision(1)<<"lambda="<<lambda
                 <<std::setprecision(6)<<" w="<<w<<" train_MSE="<<mse(w,y)
                 <<" validation_MSE="<<mse(w,valid)<<"\n";
    }
    // STEP 4: Identical perturbations make the language outputs comparable.
    std::array<double,5> noise{{-1,1,0,-1,1}};
    std::array<double,2> raw{},regularized{};
    for (int j=0;j<2;++j) {
        double sign=j==0?-1:1,cross=0;
        for (int i=0;i<5;++i) cross+=x[i]*(2*x[i]+sign*noise[i]);
        raw[j]=cross/sxx;regularized[j]=cross/(sxx+5*.2);
    }
    std::cout<<"two_fits_unregularized="<<raw[0]<<","<<raw[1]<<"\n";
    std::cout<<"two_fits_regularized="<<regularized[0]<<","<<regularized[1]<<"\n";
    std::cout<<"scope=two controlled noise patterns, not a statistical variance estimate\n";
}

练习2

迁移：把特征改为100x，若仍用相同lambda惩罚新权重，约束是否相同？

提示：

为保持预测，新权重等于旧权重的1/100。

参考：

不相同。相同预测的新权重平方变成原来的1/10000，惩罚大幅变弱。若只做单位转换且要保持原惩罚，可把新lambda乘10000；实际多特征通常先在训练部分标准化并记录约定。

开放讲解题

为什么训练误差上升可能是正则化的正常结果？

优化目标同时追求拟合与小权重，允许牺牲部分训练拟合。是否值得要看同一开发评价尺度下的泛化表现，而不是只看训练MSE。

怎样区分优化曲线和数据学习曲线？

优化曲线固定数据和模型，横轴是更新次数；数据学习曲线固定验证集，对不同训练样本量重新拟合，横轴是样本数。二者回答训练是否完成和增加数据是否有用这两个不同问题。
