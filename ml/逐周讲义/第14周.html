把注意力算出来：Q、K、V与因果遮罩

011 查询、键和值分别回答什么问题

一个位置需要从上下文选择有用信息。查询Q表示“我当前要找什么”，键K表示“每个位置提供怎样的匹配线索”，值V表示“真正汇总的内容”。这些只是便于理解的角色描述，实际数值由可学习线性投影产生，不是程序里写了自然语言问题。

长度T、表示宽度d的输入X分别乘W_Q、W_K、W_V得到Q、K、V。一个查询与所有键点积，形成对各位置的分数；softmax把一行分数变成非负且和为1的权重，再加权求和各位置的V。QK转置后是(T,T)，左维表示谁在查询，右维表示读取谁。

缩放除以sqrt(d_k)用于控制点积随维度增大而变大的尺度，避免softmax过早变得非常尖锐。它不是把每个向量强制归一到长度1。softmax计算先减去该行最大值，数学上概率不变，却降低指数溢出的风险。本例用已经给定的Q/K/V，先掌握核心运算，再把投影矩阵加入模型。

Attention Is All You Need原论文是编码器—解码器模型，本课程HW4是GPT2式仅解码器自回归模型。共享的机制是注意力、前馈层、残差等构件，不能把结构图一模一样套用。阅读时先定位缩放点积公式和遮罩，再解释每条箭头，不要求本周复现翻译实验。

点击放大

softmax沿键位置逐行执行。每个查询得到一个上下文加权和。

逐个认识符号

  • Q：T×d_k查询矩阵

  • K：T×d_k键矩阵

  • V：T×d_v值矩阵

  • M：T×T遮罩

  • A：T×T注意力权重

  • O：T×d_v输出

022 因果mask不是把未来乘零这么简单

对于第i个查询，所有j>i的键位置必须不可见。把它们的logit设为负无穷，再做softmax，它们的权重成为0。若只是把未来分数设为0，exp(0)=1，未来仍会拿到概率；若softmax后把权重乘0却不重新归一化，则权重和改变，输出尺度也改变。

本页使用j≤i的下三角可见区域。为什么可以看到自己？因为位置i输入的是当前token，位置i输出预测的是下一个token，当前token属于合法上下文。若标签没有偏移，却仍允许看到自己，就可能变成复制输入答案。mask和target shift必须一起核查。

每一行至少保留一个可见位置，才能让softmax有定义。全负无穷行会在减最大值时产生无效运算；加入padding mask时尤其要避免完全遮住某些查询。不同库对布尔mask中True表示允许还是禁止可能有不同约定，不应只凭变量名猜；本页直接用数值分数说明机制。

前缀不变量是可执行的因果检查：在评估模式、关闭随机Dropout的条件下，改变最后token的表示，前面各位置输出应保持不变。只检查最终loss不足以发现泄漏，因为泄漏可能让loss更好看。本页同时做不加mask的对照，显示前面输出会被未来改动影响。

第二和第三行的加权和

033 位置、复杂度与机制边界

不带位置表示且没有mask的自注意力，对输入位置做同样置换时，输出也会相应置换，这叫置换等变；它没有凭空知道第几个位置的能力。因果mask本身引入了顺序限制，不能把无mask时的置换结论不加条件地照搬给自回归模型。但仅靠可见范围并不等同于完整的位置编码，因此实际模型通常显式加入位置表示。

HW4使用GPT2式学习位置嵌入：颜色ID查表得到内容向量，位置编号查另一张表得到位置向量，二者相加。位置容量限制可接收的最大序列长度。像素按行扫描还把二维结构变成一维顺序，这是一种建模选择，不会自动保留所有二维邻接关系。

朴素全注意力存储T×T分数矩阵，长度翻倍时这部分元素数变成4倍；但整个模型总计算还包括投影和前馈层，不能用一个平方关系描述全部成本。本周手写代码用小数组，是为了看清索引和mask，没有宣称达到库算子的性能。

练习顺序是先不看程序手算一行，再运行核对，随后故意把mask条件反向、去掉缩放或改softmax维度，并预测结果。只看彩色热图容易产生“哪个位置重要”的故事；注意力权重本身不是因果解释，模型还含投影、残差与其他层，解释必须有受控干预支持。

Python与C++机制示例

下面的小程序验证关键机制；完整项目须按本周交付要求另行完成。

Python

"""Causal attention uses rows as query positions and columns as key positions."""
import math
# STEP 1
q = [[1.,0.],[0.,1.],[1.,1.]]
k = [[1.,0.],[0.,1.],[1.,1.]]
v = [[1.,2.],[3.,4.],[5.,6.]]
def softmax(scores):
    mx = max(scores)
    weights = [math.exp(s-mx) for s in scores]
    return [w/sum(weights) for w in weights]
# STEP 2
def attention(q,k,v,causal):
    rows, outputs = [], []
    for i,query in enumerate(q):
        scores = [sum(a*b for a,b in zip(query,key))/math.sqrt(2) for key in k]
        scores = [s if not causal or j<=i else -math.inf for j,s in enumerate(scores)]
        a = softmax(scores)
        rows.append(a)
        outputs.append([sum(a[j]*v[j][d] for j in range(len(v))) for d in range(2)])
    return rows,outputs
# STEP 3
weights,out = attention(q,k,v,True)
for i in range(3):
    print(f'row{i}_weights='+' '.join(f'{a:.6f}' for a in weights[i]))
    print(f'row{i}_output='+' '.join(f'{a:.6f}' for a in out[i]))
assert all(abs(sum(row)-1)<1e-12 for row in weights)
# STEP 4
q2,k2,v2 = [row[:] for row in q],[row[:] for row in k],[row[:] for row in v]
q2[2],k2[2],v2[2] = [9.,-7.],[9.,-7.],[80.,-40.]
altered = attention(q2,k2,v2,True)[1]
prefix_ok = out[:2] == altered[:2]
unmasked_changes = attention(q,k,v,False)[1][0] != attention(q2,k2,v2,False)[1][0]
print(f'causal_prefix_unchanged={prefix_ok} unmasked_prefix_changes={unmasked_changes}')
assert prefix_ok and unmasked_changes

C++

#include <utility>
#include <vector>
#include <array>
#include <cmath>
#include <limits>
#include <algorithm>
#include <iostream>
#include <iomanip>
#include <cassert>
using Vec=std::array<double,2>; using Mat=std::vector<Vec>;
// STEP 1
std::vector<double> softmax(const std::vector<double>& s) {
    double mx=*std::max_element(s.begin(),s.end()),total=0; std::vector<double> a;
    for(double v:s) {a.push_back(std::exp(v-mx));total+=a.back();}
    for(auto& v:a) v/=total;
    return a;
}
// STEP 2
std::pair<std::vector<std::vector<double>>,Mat> attention(const Mat& q,const Mat& k,const Mat& v,bool causal) {
    std::vector<std::vector<double>> weights; Mat outputs;
    for(std::size_t i=0;i<q.size();++i) {
        std::vector<double> scores;
        for(std::size_t j=0;j<k.size();++j)
            scores.push_back(causal&&j>i?-std::numeric_limits<double>::infinity():(q[i][0]*k[j][0]+q[i][1]*k[j][1])/std::sqrt(2.));
        auto a=softmax(scores); Vec out{};
        for(std::size_t j=0;j<v.size();++j) for(int d=0;d<2;++d) out[d]+=a[j]*v[j][d];
        weights.push_back(a); outputs.push_back(out);
    }
    return {weights,outputs};
}
int main() {
    Mat q{{1,0},{0,1},{1,1}},k=q,v{{1,2},{3,4},{5,6}};
    // STEP 3
    auto result=attention(q,k,v,true);
    std::cout<<std::fixed<<std::setprecision(6);
    for(int i=0;i<3;++i) {
        std::cout<<"row"<<i<<"_weights="; double sum=0;
        for(int j=0;j<3;++j) {std::cout<<(j?" ":"")<<result.first[i][j];sum+=result.first[i][j];}
        assert(std::abs(sum-1)<1e-12);
        std::cout<<"\nrow"<<i<<"_output="<<result.second[i][0]<<' '<<result.second[i][1]<<'\n';
    }
    // STEP 4
    Mat q2=q,k2=k,v2=v; q2[2]={9,-7};k2[2]={9,-7};v2[2]={80,-40};
    auto altered=attention(q2,k2,v2,true).second;
    bool prefix=result.second[0]==altered[0]&&result.second[1]==altered[1];
    bool changes=attention(q,k,v,false).second[0]!=attention(q2,k2,v2,false).second[0];
    std::cout<<"causal_prefix_unchanged="<<(prefix?"True":"False")<<" unmasked_prefix_changes="<<(changes?"True":"False")<<'\n';
    assert(prefix&&changes);
}

逐步解释

输入角色与稳定softmax

Q/K/V是按行存储的二维列表或vector。softmax减行最大值，再指数、求和、归一化；负无穷的指数为0。

自查：指出Q的第1行和V的第1行在运算中分别做什么。

查询行到上下文输出

外层i是查询；对每个键j算点积并缩放；j>i设−∞；随后按列分量d汇总V。C++返回权重与输出便于检查。

自查：确认softmax在键位置上做，输出每行仍是2维。

显示可核对的每一行

程序打印三行权重和输出，并检查每行权重和为1。不是只打印最终数组形状。

自查：手算第二行的两项概率，与六位小数输出比较。

未来扰动与无mask对照

同时改最后行Q/K/V，保留前面行；比较因果输出前两行不变，再确认无mask首行会变。

自查：若开启Dropout，说明为何应先eval再做这类精确比较。

练习1

基础：Q和K全为0，因果mask下三行权重分别是什么？

提示：

所有可见分数相等。

练习2

实现：故意把被遮位置分数设成0，检查前缀不变量。

提示：

exp(0)不是0。

第一行本应只有一个非零权重。

参考：

第一行会把概率分给未来位置，因此改变最后V可能改变首行输出。不变量断言应失败。修复为softmax前置−∞；仅在softmax后乘0还需重新归一化，否则不是相同定义。

练习3

迁移：把序列长度从400改成64，需要核对哪些地方？

提示：

不仅改数据shape。

参考：

核对颜色扫描顺序、位置嵌入容量、生成前缀与补全总长，以及损失分母。对64个像素采用sequence[:-1]与sequence[1:]时，训练输入和目标都长63，训练注意力mask为63×63。64是完整序列长度或位置容量；若预建64×64因果表，需要切到实际输入长度，生成阶段的mask随前缀长度变化。记录替代合成数据，不能与400像素官方分数直接比较。

开放讲解题

生成是串行的，训练为什么可以并行？

训练拥有完整真实序列，在因果mask下每个位置独立地使用合法真实前缀，矩阵运算可并行计算所有位置。生成缺少未来token，后一个位置需等待前一个采样结果。

单头注意力的输入输出形状怎样变化？

输入X为T×d，Q/K为T×d_k，V为T×d_v，分数与权重为T×T，乘V后输出T×d_v。批维只是在外面复制这些计算，softmax沿每个查询的键位置维度。
