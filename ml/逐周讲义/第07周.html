01决策树通过问题逐步分割空间

线性分类器把所有特征加权成一个分数；树则不断问“某列是否不超过某个阈值”。例如面积≤50先走左边，否则右边，再分别询问其他特征。一条根到叶的路径表示一组条件的交集；不同叶子形成分段区域。叶子可输出该区域内多数类或类别比例，回归树则常输出均值。

怎样选一个问题？分类树希望分裂后的子节点更纯。Gini不纯度为1减各类比例平方和；纯节点为0，二分类各一半时为0.5。比较分裂时，按子节点样本数加权，不能只把左右Gini简单平均，否则很小的纯节点可能得到不恰当优势。候选阈值可取排序后相邻不同数值中点。

选择当前最好分裂是贪心策略，不保证整棵固定深度树全局最好。不断加深可记住训练数据，max_depth、min_samples_leaf等参数限制容量。单个样本改变可能使首个分裂变化，随后整棵树都改变，这是树容易出现高方差的直觉。树的规则可以检查，但大树不因此自动容易解释。

点击放大

节点S内类别越混合，不纯度通常越高。

逐个认识符号

  • S：当前节点的训练样本集合

  • p_k：节点内类别k比例；K：类别数

点击放大

左右子节点不纯度按样本数加权。

逐个认识符号

  • S_L、S_R：分裂后的左右样本集合

  • n_L、n_R：各自样本数；n=n_L+n_R

一起算一个例子

枚举两个候选分裂

  1. x=(1,2,3,4,5,6)，y=(0,0,1,0,1,1)，父节点正负各3个，Gini=0.5。

  2. 阈值2.5：左侧(0,0)纯，右侧(1,0,1,1)正类比例3/4，Gini=1-9/16-1/16=0.375。

  3. 加权不纯度=2/6×0+4/6×0.375=0.25，下降0.25。

  4. 阈值3.5：左侧(0,0,1)、右侧(0,1,1)，两边Gini都4/9，加权仍4/9≈0.444444。

  5. 阈值4.5也得到0.25，本程序约定平票选较小阈值，因此选2.5。

先写计数再计算分裂分数；树桩只做这一次分裂。

02Bagging与随机森林：让不同树不要总犯同样的错

Bagging从训练集中有放回抽取若干与原样本数相同的数据集，各自训练模型，再平均预测或投票。有放回意味着某个样本可能出现多次，也可能一次不出现。多个树若完全一样，平均就没有额外帮助；效果来自误差不完全相关时的组合。它常用于降低高方差模型的波动，但不是保证每次准确率都提高。

随机森林在样本抽样之外，通常还在分裂时随机选择一部分候选特征，降低树之间的相关性。本页只有一个特征，三组固定重采样索引只是bagging机制演示，不能称为训练了完整随机森林。代码保存固定索引而不用两套语言各自的随机数引擎，是为了让Python与C++产生可比较结果，不是取消随机化的一般建议。

树一般不依赖特征绝对尺度来比较一个特征上的排序，所以标准化不像近邻或带L2的线性模型那样关键。但缺失值、类别编码和特征生成仍需遵守训练边界，具体库是否支持缺失值要核对。集成通常牺牲单棵树的直观路径解释，报告时应说清这个权衡。

一起算一个例子

多数投票不等于概率平均

  1. 三棵树对一个样本的类别预测为0、1、1，多数投票得到1。

  2. 如果输出的是正类概率0.49、0.51、0.51，平均为0.5033，也得到1。

  3. 但概率若为0.01、0.51、0.51，平均0.3433得到0，而类别投票仍为1。

必须注明聚合的是离散类别还是概率；两者可能不同。

03Boosting：后一个模型修正当前组合的错误

Boosting不是各树独立训练后投票，而是按顺序添加模型。以平方误差回归为例，先用训练标签均值作为常数预测，计算真实值减当前预测的残差，再训练一棵小树拟合这些残差，最后乘一个较小学习率加回去。下一轮残差来自已经更新的组合，因此后面的模型依赖前面。

对半平方损失，预测值方向的负梯度就是y-f(x)；一般损失的gradient boosting拟合相应负梯度，未必是普通数值残差。分类任务中不能把0/1标签减去最终类别就当通用提升算法。学习率和树数共同控制拟合过程，更多轮也可能过拟合，需要开发集选择或早停。

Bagging主要利用独立扰动后的组合；boosting强调逐步修正当前模型。两者都能改善预测，但不能简单说一个只降方差、一个只降偏差，所有情形都如此。比较时看数据、弱学习器、正则和预算，本周只把一种集成方法深入到能解释。

点击放大

把新弱模型的输出乘步长后加到已有组合。

逐个认识符号

  • F_m：第m轮后的组合预测

  • h_m：本轮拟合残差或负梯度的小模型

  • eta：添加步长，与树结构参数不同

一起算一个例子

一轮平方损失boosting

  1. 训练目标为(1,1,3,3)，初始均值预测F0=2，MSE=1。

  2. 残差为(-1,-1,1,1)，树在中间分裂可给左右叶输出-1与1。

  3. 步长eta=0.5后预测为(1.5,1.5,2.5,2.5)，MSE=0.25。

  4. 若只用0/1投票，无法表示这次数值残差修正。

本例验证一轮残差更新，不代表完整梯度提升分类器。

04kNN与核方法：另一种选择边界的方式

k近邻保存训练样本，预测时找到距离最近的k个点，再投票或平均。k很小容易追随局部噪声，k很大可能抹掉真实局部结构。距离对量纲敏感，因此通常把Scaler放在Pipeline中；在高维空间里距离区分能力也可能变弱。kNN不通过梯度训练权重，但仍使用数据建立预测规则，不能说它没有学习过程或没有成本。

支持向量机寻找兼顾间隔与误分类惩罚的分界。核函数允许通过相似度隐式表达更丰富特征关系，例如RBF核随两点平方距离增加而衰减。C调节间隔与误差的取舍，gamma控制RBF局部性；二者都不能看测试集调。这里要求结构直觉和一个可运行库对照，不要求本周从零实现二次规划求解器。

项目A复用第5周相同开发折，比较逻辑回归、浅树，以及随机森林或梯度提升中的一种，再从kNN/SVM中选一个小对照。可以先固定浅树max_depth=3、森林100棵，近邻k=5，作为起始配置；不是最佳参数推荐。给各方法相近的调参次数，报告时间、警告与分折指标，不为了让某模型获胜而改变划分。

点击放大

RBF核把距离转成相似度；越远越小。

逐个认识符号

  • x、x'：两个特征向量；||x-x'||²：平方欧氏距离

  • gamma：正的局部尺度参数；k：核相似度

一起算一个例子

尺度怎样影响近邻

  1. 样本A与查询点在两列上的差为(1,10)，平方距离101；样本B的差为(3,0)，平方距离9，所以B更近。

  2. 若第二列单位缩小100倍，A距离变成1.01，而B仍9，最近者变成A。

  3. 这不是数据事实变化，而是距离定义中各列权重发生变化。

比较基于距离的方法时，标准化和任务相关的距离定义要一起说明。

05代码桥梁：排序、去重与模型容器

Python的sorted(set(...))先去掉重复特征值再升序排列，zip(candidates,candidates[1:])配相邻值；model[:2]按不纯度、阈值顺序比较元组。C++先sort，再用unique把重复值移到尾部，最后erase真正缩短vector；只调用unique而不erase会留下逻辑垃圾区。

C++的Stump结构体给字段命名，Python本例用四元组并用下标读取，阅读时对照impurity、threshold、left、right。固定示例都有可用分裂；扩展到常数列或空数据时，fit必须返回纯叶/错误而不能继续读取不存在的best。std::numeric_limits::infinity()只是初始化最差分数的哨兵。

Python

"""Week 07: exhaustive stump split and fixed bootstrap illustration."""
# STEP 1: Ordered x lets us enumerate every distinct candidate threshold.
x, y = [1., 2., 3., 4., 5., 6.], [0, 0, 1, 0, 1, 1]
# STEP 2: Gini measures class mixture; an empty group has weight zero.
def gini(labels):
    if not labels:
        return 0.
    p = sum(labels) / len(labels)
    return 2 * p * (1 - p)
def fit(indices):
    candidates = sorted(set(x[i] for i in indices))
    best = None
    for a, b in zip(candidates, candidates[1:]):
        t = (a + b) / 2
        left = [y[i] for i in indices if x[i] <= t]
        right = [y[i] for i in indices if x[i] > t]
        impurity = (len(left)*gini(left)+len(right)*gini(right))/len(indices)
        model = (impurity, t, int(sum(left)*2 > len(left)), int(sum(right)*2 > len(right)))
        if best is None or model[:2] < best[:2]:
            best = model
    return best
# STEP 3: Fit one depth-one tree; ties choose the smaller threshold/class.
model = fit(list(range(6)))
print(f"stump_threshold={model[1]:.1f} weighted_gini={model[0]:.6f}")
def predict(model, value):
    return model[2] if value <= model[1] else model[3]
print("stump_predictions=" + ",".join(str(predict(model, v)) for v in x))
# STEP 4: Fixed resampled index lists illustrate bagging without RNG drift.
bootstraps = [[0,0,1,3,4,5], [0,1,2,2,4,5], [0,1,3,3,4,5]]
trees = [fit(indices) for indices in bootstraps]
ensemble = [int(sum(predict(tree,v) for tree in trees) >= 2) for v in x]
print("bagging_predictions=" + ",".join(map(str, ensemble)))
# STEP 5: A squared-loss boosting step fits residuals, not label votes.
target = [1., 1., 3., 3.]
initial = sum(target) / len(target)
residual = [t - initial for t in target]
leaf = [sum(residual[:2])/2]*2 + [sum(residual[2:])/2]*2
updated = [initial + .5*r for r in leaf]
before = sum((initial-t)**2 for t in target)/4
after = sum((p-t)**2 for p,t in zip(updated,target))/4
print(f"boosting_MSE_before={before:.6f} after={after:.6f}")
print("scope=three fixed stumps; not a trained random forest")

C++

// Week 07: C++17, explicit tree scoring and residual fitting.
#include <algorithm>
#include <array>
#include <iomanip>
#include <iostream>
#include <limits>
#include <vector>
// STEP 1: Labels and features have the same six sample indices.
const std::vector<double> x{1,2,3,4,5,6};
const std::vector<int> y{0,0,1,0,1,1};
struct Stump {double impurity,threshold;int left,right;};
// STEP 2: Loop over sorted unique feature values, then score both children.
double gini(const std::vector<int>& labels) {
    if (labels.empty()) return 0;
    double p=0;for (int label:labels) p+=label;
    p/=labels.size();return 2*p*(1-p);
}
Stump fit(const std::vector<int>& indices) {
    std::vector<double> values;
    for (int i:indices) values.push_back(x[i]);
    std::sort(values.begin(),values.end());
    values.erase(std::unique(values.begin(),values.end()),values.end());
    Stump best{std::numeric_limits<double>::infinity(),0,0,0};
    for (std::size_t j=1;j<values.size();++j) {
        double t=(values[j-1]+values[j])/2;
        std::vector<int> left,right;
        for (int i:indices) (x[i]<=t?left:right).push_back(y[i]);
        double score=(left.size()*gini(left)+right.size()*gini(right))/indices.size();
        int l=0,r=0;for(int v:left)l+=v;for(int v:right)r+=v;
        if (score<best.impurity) best={score,t,2*l>int(left.size()),2*r>int(right.size())};
    }
    return best;
}
int predict(const Stump& m,double value){return value<=m.threshold?m.left:m.right;}
int main() {
    // STEP 3: One stump is fully inspectable.
    Stump model=fit({0,1,2,3,4,5});
    std::cout<<std::fixed<<std::setprecision(1)<<"stump_threshold="<<model.threshold
             <<std::setprecision(6)<<" weighted_gini="<<model.impurity<<"\n";
    std::cout<<"stump_predictions=";
    for(int i=0;i<6;++i)std::cout<<(i?",":"")<<predict(model,x[i]);
    std::cout<<"\n";
    // STEP 4: Resampling changes samples; these stumps use the only feature.
    std::vector<Stump> trees{fit({0,0,1,3,4,5}),fit({0,1,2,2,4,5}),fit({0,1,3,3,4,5})};
    std::cout<<"bagging_predictions=";
    for(int i=0;i<6;++i){
        int votes=0;for(const Stump& tree:trees)votes+=predict(tree,x[i]);
        std::cout<<(i?",":"")<<(votes>=2);
    }
    std::cout<<"\n";
    // STEP 5: Squared-loss residuals give the direction for a boosting step.
    std::array<double,4> target{{1,1,3,3}},residual{},leaf{},updated{};
    double initial=2,before=0,after=0;
    for(int i=0;i<4;++i)residual[i]=target[i]-initial;
    leaf={{(residual[0]+residual[1])/2,(residual[0]+residual[1])/2,
           (residual[2]+residual[3])/2,(residual[2]+residual[3])/2}};
    for(int i=0;i<4;++i){
        updated[i]=initial+.5*leaf[i];
        before+=(initial-target[i])*(initial-target[i])/4;
        after+=(updated[i]-target[i])*(updated[i]-target[i])/4;
    }
    std::cout<<"boosting_MSE_before="<<before<<" after="<<after<<"\n";
    std::cout<<"scope=three fixed stumps; not a trained random forest\n";
}

逐步解释

固定顺序与标签

x已排序，标签包含中间反例，因此没有一个完美单次分裂。C++struct把不纯度、阈值与左右预测绑定在一起。

自查：先猜哪两个阈值可能平票。

枚举并计分

排序去重后取相邻中点；按阈值划分标签；gini算比例，加权得总分。平票保留较小阈值，叶子类别平票取0。示例数据保证候选可分；通用树还需处理常数特征和空集合。

自查：为何不能简单平均左右Gini？

一棵树桩预测

fit只产生一次分裂，predict把输入送入相应叶子。模型会把x=4分错，这是有限容量的结果。

自查：输出规则能否写成一句条件语句？

固定重采样与投票

三组索引允许重复，体现有放回抽样；每组重新fit一个树桩。按三票多数决定类别，这里不平均叶子概率。

自查：为何这还不是完整随机森林？

残差提升一步

以均值初始化，按预先说明的左右组拟合残差均值，再以0.5添加；计算更新前后MSE。此处固定了分裂，重点是加法更新机制。

自查：残差使用真实值减预测，正负号是否与MSE里的残差定义冲突？

开放讲解题

用代码结构区别bagging和boosting。

Bagging循环中每个模型可从原始训练标签独立拟合不同重采样集，最后聚合；boosting每轮先用当前组合预测计算新目标，再训练并更新组合，存在前后依赖。

树模型可解释是否意味着没有证据边界？

可以追踪路径只说明决策规则可检查。若训练数据泄漏、划分不合理或分布变化，路径清楚也不能证明未来可靠；特征重要性或分裂条件也不自动代表因果。
