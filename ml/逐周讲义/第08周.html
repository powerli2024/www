PCA、聚类与论文导读：压缩数据不等于理解标签

01PCA问的是哪个方向变化最多

二维数据可能主要沿一条斜线变化，直接保留第一列会浪费第二列中的共同信息。PCA寻找一个单位方向，使数据投影到该方向后的方差最大。它首先去掉均值，研究围绕平均样本的变化；如果不中心化，方向可能主要指向原点到数据团的位置，而不是数据自身的变化方向。

设中心化矩阵为Z，单位向量v给出方向，每个样本的低维坐标是z_i·v。投影方差可写成v^T C v，其中C=Z^T Z/n是本课协方差约定。要求v长度为1，是为了避免把v任意放大就让方差无限大。对称协方差矩阵的最大特征值对应最大方差方向；特征向量是被矩阵作用后方向保持不变、只缩放的向量。

PCA方向正负号不唯一：v和-v描述同一条轴，投影坐标符号相反但重建相同。库可能返回与手算相反的方向，不能因此判断实现错误。有些库协方差除以n-1，解释方差数值会缩放，但同一数据的主方向与解释方差比例不变。

点击放大

PCA方向是中心化协方差的单位特征向量，lambda表示该方向方差。

逐个认识符号

  • Z：每列减去训练均值后的数据矩阵

  • C：本课采用除以n的协方差矩阵

  • v：单位方向；lambda：对应特征值；n：训练样本数

一起算一个例子

四个共线点的完整PCA

  1. 数据(1,1),(2,2),(3,3),(4,4)，均值为(2.5,2.5)。

  2. 中心化后为(-1.5,-1.5),(-0.5,-0.5),(0.5,0.5),(1.5,1.5)。

  3. 两个方差和协方差都为(2.25+0.25+0.25+2.25)/4=1.25，所以C的四个元素均为1.25。

  4. v=(1/√2,1/√2)时Cv=(2.5/√2,2.5/√2)=2.5v，因此主特征值2.5。

  5. 另一方向(1/√2,-1/√2)的特征值为0。

所有变化都沿第一条方向；这里解释方差比例为100%，是特意选的共线教学例子。

02投影、重建与分类效果是不同目标

投影得到一个数后，可沿方向把它放回原空间，再加训练均值。只保留一个方向时，垂直于它的信息被丢弃。PCA在适当的正交投影条件下也对应最小化平方重建误差，因此“最大保留方差”和“最小重建误差”是同一结构的两种视角。

然而方差大不代表对标签有用。假设第一列是大量无关亮度变化，第二列只差一点点却决定类别，PCA可能优先保留第一列，导致分类变差。画出的二维散点分开也不能自动证明预测可靠，因为可能使用了全数据拟合、挑选了漂亮投影或忽略了未展示样本。分类效果必须通过相同开发协议比较。

项目A应把StandardScaler、PCA、LogisticRegression放在一个Pipeline中，让Scaler和PCA都只fit每折训练数据。与不加PCA的Pipeline比较，使用相同折、同样的分类器候选预算，并报告保留维数、解释方差和开发指标。解释方差是输入重建信息，不是准确率的保证；是否标准化也改变PCA偏重的方向，应在实验协议中固定。

点击放大

先投影到一维坐标，再沿原方向重建。

逐个认识符号

  • x_i：原样本；mu：训练均值向量

  • t_i：投影坐标；v：保留的单位主方向

  • x̂_i：仅使用保留方向得到的重建

一起算一个例子

投影后还原第一个点

  1. x=(1,1)，mu=(2.5,2.5)，v=(1/√2,1/√2)。

  2. 投影t=(-1.5-1.5)/√2=-3/√2≈-2.121320。

  3. 重建mu+t*v=(2.5-1.5,2.5-1.5)=(1,1)。

  4. 若v改为-v，t也改号，乘积t*v不变。

本例重建误差为0不说明任意二维数据都能无损压成一维。

03k-means没有真实标签，却不是没有目标

k-means给定簇数K，寻找K个中心和样本分配，使各样本到所分中心的平方距离总和尽可能小。它交替做两步：固定中心，把每个样本分给最近中心；固定分配，把每个簇中心改为该簇均值。均值是平方误差下最优常数预测，这与第一周均值基线相呼应。

每一步不会增加该目标，但整体问题不是简单凸优化，不同初始化可能收敛到不同局部结果。K也是人为给定，不是自动知道世界有多少类。空簇需要明确策略，本页保留旧中心；成熟库可能重新初始化。尺度、异常值和不适合球形簇的数据都会影响结果，不能仅因程序稳定结束就说发现了自然类别。

聚类输出的编号0或1只是名字。交换两个中心的编号，不改变分组质量，却可能把逐项比较标签的所谓准确率从1变成0。若使用真实标签作外部评价，应采用对编号置换不敏感的度量，如调整兰德指数，或明确在开发数据上拟合标签匹配。不要把真实标签偷偷用于选择最佳聚类再称完全无监督发现。

点击放大

每个样本到它所属簇中心的平方距离之和。

逐个认识符号

  • c_i：样本i的簇编号；mu_c_i：对应簇中心

  • K：中心数量；J：k-means目标值

  • ||·||²：各坐标差平方求和

一起算一个例子

一次分配与一次中心更新

  1. 一维点为0、1、4、5，K=2，初始中心0和4。

  2. 最近中心分配为(0,0,1,1)，目标值0²+1²+0²+1²=2。

  3. 更新中心为(0+1)/2=0.5与(4+5)/2=4.5。

  4. 重新分配不变，目标值4×0.5²=1，已稳定。

簇编号可互换，几何分组不变；本例没有使用任何真实类别。

06代码桥梁：解析特征向量与聚类循环边界

Python的sum(v*d for ...)逐坐标实现点积，C++显式相乘相加。math.sqrt与std::sqrt只求平方根；本页最大特征值来自二维二次方程。方向向量除以norm是在归一化，若norm为0会失败；当前固定共线数据不触发，但任意对角协方差可能触发，不能将此代码冒充通用PCA库。

Python的min(range(2),key=...)返回最近中心编号，C++比较两个平方距离；距离相等时都选0。中心为空时保留旧值是本例明确约定。updated==centers使用精确相等对这组有理小例子足够；一般浮点数据应定义容差与最大迭代数，并在停止后重新核对分配和目标值。

Python

"""Week 08: analytic 2D PCA and one-dimensional k-means."""
# STEP 1: Centering is fitted on the four training points.
import math
x = [(1., 1.), (2., 2.), (3., 3.), (4., 4.)]
mean = [sum(row[j] for row in x)/len(x) for j in range(2)]
centered = [[row[j]-mean[j] for j in range(2)] for row in x]
# STEP 2: Divide by n for this teaching covariance; n-1 has same directions.
a = sum(row[0]**2 for row in centered)/len(x)
b = sum(row[0]*row[1] for row in centered)/len(x)
c = sum(row[1]**2 for row in centered)/len(x)
largest = (a+c+math.sqrt((a-c)**2+4*b*b))/2
direction = [b, largest-a]
norm = math.sqrt(sum(v*v for v in direction))
direction = [v/norm for v in direction]
# STEP 3: Project, then reconstruct using the same mean and direction.
scores = [sum(v*d for v,d in zip(row,direction)) for row in centered]
reconstructed = [[mean[j]+s*direction[j] for j in range(2)] for s in scores]
error = sum((u-v)**2 for row,out in zip(x,reconstructed) for u,v in zip(row,out))/len(x)
print(f"mean={mean[0]:.6f},{mean[1]:.6f} eigenvalue={largest:.6f}")
print("direction=" + ",".join(f"{v:.6f}" for v in direction))
print(f"reconstruction_squared_error={error:.6f}")
# STEP 4: k-means alternates nearest-center assignment and center averaging.
points, centers = [0., 1., 4., 5.], [0., 4.]
for _ in range(10):
    assignment = [min(range(2), key=lambda j: (p-centers[j])**2) for p in points]
    updated = []
    for j in range(2):
        group = [p for p,label in zip(points,assignment) if label == j]
        updated.append(sum(group)/len(group) if group else centers[j])
    if updated == centers:
        break
    centers = updated
print("centers=" + ",".join(f"{v:.6f}" for v in centers))
print("cluster_ids=" + ",".join(map(str,assignment)))
print("scope=PCA and clustering mechanisms; no TabPFN inference")

C++

// Week 08: C++17 two-dimensional PCA and one-dimensional k-means.
#include <array>
#include <cmath>
#include <iomanip>
#include <iostream>
// STEP 1: Estimate the center from training samples only.
int main() {
    using Point=std::array<double,2>;
    std::array<Point,4> x{{{{1,1}},{{2,2}},{{3,3}},{{4,4}}}},centered{};
    Point mean{{0,0}};
    for(const Point& p:x)for(int j=0;j<2;++j)mean[j]+=p[j]/4;
    for(int i=0;i<4;++i)for(int j=0;j<2;++j)centered[i][j]=x[i][j]-mean[j];
    // STEP 2: Analytic eigenvalue for a symmetric 2 by 2 matrix.
    double a=0,b=0,c=0;
    for(const Point& p:centered){a+=p[0]*p[0]/4;b+=p[0]*p[1]/4;c+=p[1]*p[1]/4;}
    double largest=(a+c+std::sqrt((a-c)*(a-c)+4*b*b))/2;
    Point direction{{b,largest-a}};
    double norm=std::sqrt(direction[0]*direction[0]+direction[1]*direction[1]);
    for(double& v:direction)v/=norm;
    // STEP 3: Projection and reconstruction should recover collinear samples.
    double error=0;
    for(int i=0;i<4;++i){
        double s=centered[i][0]*direction[0]+centered[i][1]*direction[1];
        for(int j=0;j<2;++j){
            double residual=x[i][j]-(mean[j]+s*direction[j]);
            error+=residual*residual/4;
        }
    }
    std::cout<<std::fixed<<std::setprecision(6)<<"mean="<<mean[0]<<","<<mean[1]
             <<" eigenvalue="<<largest<<"\n";
    std::cout<<"direction="<<direction[0]<<","<<direction[1]<<"\n";
    std::cout<<"reconstruction_squared_error="<<error<<"\n";
    // STEP 4: Alternate assignments and mean centers; retain an empty center.
    std::array<double,4> points{{0,1,4,5}};
    Point centers{{0,4}};std::array<int,4> assignment{};
    for(int step=0;step<10;++step){
        Point total{{0,0}};std::array<int,2> counts{{0,0}};
        for(int i=0;i<4;++i){
            double d0=points[i]-centers[0],d1=points[i]-centers[1];
            assignment[i]=d1*d1<d0*d0?1:0;
            total[assignment[i]]+=points[i];counts[assignment[i]]++;
        }
        Point updated=centers;
        for(int j=0;j<2;++j)if(counts[j])updated[j]=total[j]/counts[j];
        if(updated==centers)break;
        centers=updated;
    }
    std::cout<<"centers="<<centers[0]<<","<<centers[1]<<"\ncluster_ids=";
    for(int i=0;i<4;++i)std::cout<<(i?",":"")<<assignment[i];
    std::cout<<"\nscope=PCA and clustering mechanisms; no TabPFN inference\n";
}

逐步解释

中心化

Python按列求均值，C++累加每个坐标；centered保存减均值后的样本。未来样本应使用这些训练均值，不能重算。

自查：若不中心化，本例方向解释会怎样变？

二维特征值

对称2×2矩阵可用二次方程求最大特征值，再构造(b,lambda-a)并归一化。本例b非零；此构造不能直接覆盖所有退化矩阵，通用问题应使用稳定对称特征求解器。

自查：为什么方向必须单位化？

投影与重建

先点积得到一维分数，再乘方向并加均值，计算每样本总平方重建误差。方向整体反号应保持重建不变。

自查：重建0误差说明哪些数据性质？

k-means两步交替

先按当前中心分配，再按簇求均值；空簇保留原中心，中心不变时停止。本例最多10轮且会提前收敛；通用实现应报告达到迭代上限的情况。

自查：调换中心编号是否改变分组？

开放讲解题

为什么PCA也要放在交叉验证的Pipeline里？

PCA方向与均值从数据估计，即使不读标签也可能利用验证分布。每折只在训练部分拟合，才能评价面向未知样本的完整流程。

用三分钟串起前8周：为什么比较模型必须同时比较划分与预算？

模型成绩取决于训练信息、预处理、参数选择和评价样本。划分不同会改变难度，调参预算不同会给候选不同的选择机会。应先固定使用场景和开发边界，再用相同折与明确预算比较，最终测试在方案冻结后使用。
