逻辑回归：从分数到概率，再到分类决定

01为什么线性回归输出不能直接叫概率

预测是否垃圾邮件时，标签是0或1。线性分数z可以取任意实数，例如-3或4；即使把它直接四舍五入，也没有得到合理的条件概率。逻辑回归先保留线性打分，再用sigmoid把分数映射到0与1之间。所谓条件概率，是在给定特征x和当前模型参数时，模型对y=1的估计；不是“这封邮件有70%是半封垃圾邮件”。

sigmoid单调增加，因此分数越大，估计正类概率越高；z=0对应0.5。将概率阈值设为0.5时，决策边界仍是w·x+b=0，所以这是线性分类器。概率曲线非线性，不等于它能画任意弯曲边界。把二维点想成纸面上的两组，先问一条直线是否足以分开，再讨论训练。

阈值决定采取什么行动。把阈值从0.5提高到0.9，不需要重新训练，但通常会减少预测为正的样本。概率值本身不会因此改变。阈值应在开发数据上结合漏报与误报代价选择，不能用最终测试集反复寻找最好阈值。即使输出0.9，也未必在现实中达到90%的正确频率，校准问题将在第12周展开。

点击放大

线性分数经sigmoid变成正类概率估计。

逐个认识符号

  • z_i：未归一化分数，常称logit

  • p_i：模型估计的P(y_i=1|x_i)

  • sigma：sigmoid函数；w_j和b：待训练参数

一起算一个例子

同一概率，两种决定

  1. z=ln(3)≈1.098612，exp(-z)=1/3，因此p=1/(1+1/3)=0.75。

  2. 阈值0.5时输出正类；阈值0.9时输出负类。

  3. 两种规则使用相同的0.75，只是行动门槛不同。

分数、概率、阈值和类别是四个不同对象。

02交叉熵为什么会惩罚自信的错误

对一个0/1标签，伯努利模型赋给观测标签的概率是p^y(1-p)^(1-y)：若y=1，表达式留下p；若y=0，留下1-p。在给定特征与参数、并采用样本条件独立假设时，整批标签的似然是这些概率的乘积。最大化乘积容易数值下溢，取对数可把乘法变成加法，取负号则变成要最小化的损失。

单样本负对数似然就是二分类交叉熵。它在y=1时等于-log(p)，y=0时等于-log(1-p)。正确且有信心时接近0，错误却极有信心时很大。MSE也可以用于0/1输出的某些建模，但这里选择交叉熵，是因为它与伯努利概率模型和相应梯度自然一致，不能说分类在数学上绝对禁止平方损失。

对数log在本课程指自然对数，Python math.log和C++ std::log默认也是自然对数。底数不同会缩放损失和梯度，比较时要统一。不要把每个样本先四舍五入成类别后再求交叉熵：这样丢掉了概率信息，并造成不可用于普通梯度下降的阶梯决策。

点击放大

真实类别对应的概率越小，损失越大。

逐个认识符号

  • ell：一个样本的损失

  • y：0或1标签；p：预测正类概率

  • log：自然对数

一起算一个例子

比较三种自信程度

  1. y=1，p=0.5时损失-log(0.5)=0.693147。

  2. 同为y=1，p=0.9时损失0.105361；p=0.01时损失4.605170。

  3. 若y=0、p=0.9，则损失-log(0.1)=2.302585，不能仍套用-log(p)。

损失评价真实类别获得多少概率，不只统计是否越过0.5。

03链式法则把复杂表达式化成p-y

先对概率求导，得到-y/p+(1-y)/(1-p)；再乘sigmoid的导数p(1-p)。两部分相消后只剩p-y。这一步值得自己展开一次，因为后续softmax与神经网络也会反复遇到“预测概率减目标”的结构。最后对权重求导再乘对应特征，对偏置求导乘1，跨样本平均即可。

因此逻辑回归与线性回归共享“预测—残差式信号—乘特征—平均—更新”的程序结构，但信号来源与损失不同。MSE的梯度有2，交叉熵配sigmoid后的梯度没有这个2，不能把上一周代码原封不动改一个输出函数就当完成。代码用中心差分逐坐标核对初始梯度，帮助连接公式和实现。

在完全线性可分的数据上，没有正则约束的逻辑回归可以把权重越推越大，使训练交叉熵持续靠近0，而有限参数的最优点可能不存在。示例只运行固定300步，用于观察机制，不以“找到了唯一最优权重”描述它。权重大小和概率可信度也不是同一回事。

点击放大

先求分数方向的导数，再沿线性分数传回权重。

逐个认识符号

  • L：n个样本交叉熵的平均

  • p_i-y_i：分数方向的误差信号

  • x_ij：该参数影响第i个分数的倍率

一起算一个例子

一个样本的完整更新

  1. x=(2,-1)，y=1，w=(0,0)，b=0，得到z=0、p=0.5、损失0.693147。

  2. p-y=-0.5，因此权重梯度为(-1,0.5)，偏置梯度为-0.5。

  3. 学习率0.1后，w=(0.1,-0.05)，b=0.05；新z=2×0.1+(-1)×(-0.05)+0.05=0.3。

  4. 新概率约0.574443，损失约0.554355。

更新方向增加真实正类的概率；先算整组梯度，再同时更新。

04数学等价不意味着浮点计算一样安全

直接计算exp(1000)会溢出；先求概率再log也可能遇到概率被舍入成0或1。稳定sigmoid在z≥0时用1/(1+exp(-z))，在z<0时用exp(z)/(1+exp(z))，保证传入exp的指数不大于0。两种写法数学等价，但数值范围更安全。

交叉熵可以直接用logit计算成max(z,0)-y*z+log1p(exp(-abs(z)))。math.log1p(u)与std::log1p(u)计算log(1+u)，在u很小时比先算1+u再log更可靠。这些函数只计算数值，不会自动替程序求导；梯度仍来自上一节的手推公式。极端分数输出精确0或1可能是浮点舍入，不代表现实绝对确定。

练习顺序是先跑六点例子，核对初始损失与梯度；然后只改阈值，观察预测类别；再加入一个反例点，让两类不再完全可分，比较损失轨迹。最后独立造二维带噪声数据并划分训练/验证，报告分类准确率和交叉熵。六点示例只报告训练机制，不提供泛化结论。

一起算一个例子

极端分数也能稳定计算

  1. z=1000、y=1：稳定损失为1000-1000+log1p(exp(-1000))≈0。

  2. z=1000、y=0：稳定损失约1000，指出非常自信的错误。

  3. 直接计算exp(1000)容易溢出；稳定写法只计算exp(-1000)。

避免溢出是实现正确性的条件，不是模型可信度的保证。

05代码桥梁：返回值、复制与稳定数学函数

Python的evaluate返回(loss,gradient)二元组，loss,grad=...按位置拆开；训练循环中用下划线接收暂不用的损失，不表示函数没有计算它。list.copy()创建新的外层列表，本例元素都是数字，足以独立扰动；若是嵌套列表，浅复制不会复制内部行。

C++的std::pair<double,Row>把损失和三个梯度放在一起，first与second分别读取；const Row&确保评估函数不改参数。std::exp、std::log1p、std::abs来自cmath，只计算函数值。梯度由我们写的(p-y)*x给出。两语言都先保存完整gradient，再更新theta，因此同一批样本使用同一组旧参数。

Python与C++机制示例

下面的小程序验证关键机制；完整项目须按本周交付要求另行完成。

Python

"""Week 03: stable sigmoid and binary cross-entropy; standard library."""
# STEP 1: An intercept is represented by a constant final feature.
import math
x = [(-2., -1., 1.), (-1., -2., 1.), (-1., 0., 1.),
     (1., 0., 1.), (1., 2., 1.), (2., 1., 1.)]
y = [0., 0., 0., 1., 1., 1.]
theta = [0., 0., 0.]
# STEP 2: Stable formulas avoid taking log(0) or overflowing exp(1000).
def sigmoid(z):
    if z >= 0:
        return 1.0 / (1.0 + math.exp(-z))
    e = math.exp(z)
    return e / (1.0 + e)
def evaluate(t):
    g, total = [0.] * 3, 0.
    for row, target in zip(x, y):
        z = sum(a * b for a, b in zip(row, t))
        total += max(z, 0.) - target * z + math.log1p(math.exp(-abs(z)))
        for j in range(3):
            g[j] += (sigmoid(z) - target) * row[j] / len(x)
    return total / len(x), g
# STEP 3: Inspect the first gradient before any training.
loss, grad = evaluate(theta)
print(f"initial_loss={loss:.6f} gradient=" + ",".join(f"{v:.6f}" for v in grad))
h = 1e-5
for j in range(3):
    plus, minus = theta.copy(), theta.copy()
    plus[j] += h
    minus[j] -= h
    numeric = (evaluate(plus)[0] - evaluate(minus)[0]) / (2 * h)
    assert abs(numeric - grad[j]) < 1e-7
# STEP 4: All coordinates use the gradient at the same old parameter vector.
for _ in range(300):
    _, grad = evaluate(theta)
    theta = [t - 0.1 * g for t, g in zip(theta, grad)]
print(f"final_loss={evaluate(theta)[0]:.6f}")
# STEP 5: Probability and decision are separate; change only the threshold.
p = sigmoid(sum(a * b for a, b in zip((0.2, 0., 1.), theta)))
print(f"query_probability={p:.6f} class_at_0.5={int(p >= .5)} class_at_0.9={int(p >= .9)}")
print(f"extreme_probabilities={sigmoid(-1000):.1f},{sigmoid(1000):.1f}")

C++

// Week 03: C++17; math functions compute numbers, not symbolic derivatives.
#include <algorithm>
#include <array>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <utility>
#include <vector>
using Row = std::array<double, 3>;
// STEP 1: Same six samples and constant intercept feature as Python.
const std::vector<Row> x{{{-2,-1,1}},{{-1,-2,1}},{{-1,0,1}},{{1,0,1}},{{1,2,1}},{{2,1,1}}};
const std::vector<double> y{0,0,0,1,1,1};
// STEP 2: Piecewise sigmoid and log1p implement stable numerical formulas.
double sigmoid(double z) {
    if (z >= 0) return 1 / (1 + std::exp(-z));
    double e = std::exp(z);
    return e / (1 + e);
}
std::pair<double, Row> evaluate(const Row& t) {
    Row g{{0,0,0}};
    double total = 0;
    for (std::size_t i = 0; i < x.size(); ++i) {
        double z = 0;
        for (int j = 0; j < 3; ++j) z += x[i][j] * t[j];
        total += std::max(z, 0.0) - y[i] * z + std::log1p(std::exp(-std::abs(z)));
        for (int j = 0; j < 3; ++j) g[j] += (sigmoid(z)-y[i])*x[i][j]/x.size();
    }
    return {total / x.size(), g};
}
int main() {
    // STEP 3: Print and numerically check the untrained gradient.
    Row t{{0,0,0}};
    auto initial = evaluate(t);
    std::cout << std::fixed << std::setprecision(6)
              << "initial_loss=" << initial.first << " gradient="
              << initial.second[0] << "," << initial.second[1] << "," << initial.second[2] << "\n";
    for (int j = 0; j < 3; ++j) {
        Row plus = t, minus = t;
        plus[j] += 1e-5; minus[j] -= 1e-5;
        double numeric = (evaluate(plus).first-evaluate(minus).first)/2e-5;
        if (std::abs(numeric-initial.second[j]) > 1e-7) return 1;
    }
    // STEP 4: Compute a whole gradient, then update the whole vector.
    for (int step = 0; step < 300; ++step) {
        Row g = evaluate(t).second;
        for (int j = 0; j < 3; ++j) t[j] -= 0.1 * g[j];
    }
    std::cout << "final_loss=" << evaluate(t).first << "\n";
    // STEP 5: Thresholds change decisions without retraining.
    double p = sigmoid(0.2*t[0]+t[2]);
    std::cout << "query_probability=" << p << " class_at_0.5=" << (p>=.5)
              << " class_at_0.9=" << (p>=.9) << "\n";
    std::cout << std::setprecision(1) << "extreme_probabilities="
              << sigmoid(-1000) << "," << sigmoid(1000) << "\n";
}

开放讲解题

用一句话分别解释分数、概率、阈值、类别。

分数是线性加权的实数；概率是经sigmoid得到的正类估计；阈值是行动门槛；类别是把概率与门槛比较后的离散决定。

为什么稳定损失从logit计算，却仍能得到p-y梯度？

稳定写法与原交叉熵数学等价，只重新组织指数与对数来避免溢出。导数反映同一函数；数值实现应再用差分核对，而不是因为表达式看起来不同就改动目标。
