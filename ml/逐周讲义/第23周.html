最终评估与误差归因：让每一句结论都能回查

01最终测试是对冻结方案的测量

最终测试的价值来自它没有参与此前的方法选择。开始前确认基础文件、适配文件、配置、词表、来源划分和计分位置都已固定，保存一个评价清单。这里“一次”指一次预定最终评价流程，流程可包含全部预定方法和种子，并非只能调用模型一次；不允许看完结果再从测试中挑最佳配置。

基础模型和所有被选适配模型，都在相同A测试与B测试上运行teacher forcing评价。输入前缀、目标shift、mask、自然对数和计分token集合保持一致。评估关闭训练随机层并关闭梯度记录；数据使用测试清单，不借开发目录中的缓存替代。

结果先写原始记录，再计算主表；包括样本ID、模型ID、域、被计分token数、负对数概率总和、失败状态。记录实际时间和资源，即使它比预估大。若评价程序崩溃，可修复实现问题后按记录恢复同一冻结方案；不把重新评价当作改配置机会。

本周小程序只在内存中演示一次性门控，进程重启就会忘记状态。真实项目需靠持久运行记录、冻结文件和用途约束管理流程，不把这个布尔值当安全机制。程序不会读取真实测试数据，也不会替你生成最终模型分数。

什么算测试后重新选择

  1. 冻结F4、L5及三个种子，统一评估，这是预定流程。

  2. 看到L5测试更差后改用L6，再对同一测试报告“最终最佳”，属于用测试选择。

使用测试的次数不是唯一判断，是否利用结果作选择才是关键。

02汇总损失时，分母必须与指标定义一致

如果每张图被计分token数相同，先平均每张图损失与汇总总损失再除总token等价。长度不同、mask不同或有截断时，二者可能不同。项目B规定按预测token平均，因此先累加负对数概率总和，再除所有有效token数，不能把每个批次平均损失直接等权平均。

举例中gA只有2个计分token，适配B损失总和2.2，平均1.1；gB有8个，损失总和7.2，平均0.9。等图平均为1.0，token平均为9.4/10=0.94。两者都可有定义，但不能在不同方法之间混用分母。固定项目用一种主定义，必要时另报另一种并明确名称。

负对数概率必须有限且非负；真实实现可直接累加log-softmax提供的稳定对数值，避免先把极小概率取出来再log造成下溢。若样本被截断或评分失败，应按协议报告覆盖率与失败，不能把困难token从分母删除。极大损失提示低概率，但不自动说明某一种具体编码错误。

  • j：样本索引

  • L_token：项目B主评价损失

从总和到收益/遗忘

  1. 两张图token数为2与8；基础A损失总和0.8与3.2，总计4，除以10得0.4。

  2. 适配A总和1.2与4.0，平均0.52；基础B总和3.2与12.8，平均1.6。

  3. 适配B总和2.2与7.2，平均0.94。

  4. 新域收益1.6−0.94=0.66；旧域遗忘0.52−0.4=0.12。

所有四项使用相同计分位置和token权重，差值才可比较。

03误差分析是提出可区分解释，不是看图编故事

选择固定前缀和采样种子，展示全部补全，附模型与温度。不只展示最好16张，而是事先固定16个样本；如测试样本不足16则全部展示并说明数量。teacher forcing损失与自由生成图片分开分析：前者每步看到真实历史，后者会沿自己生成的历史继续，因此可能累积错误。

建立有限而清楚的错误类别，例如颜色置换未学会、形状连续性失败、重复纹理、无效颜色ID。先记录可观察事实：“第3个样本前缀后的12个位置反复出现颜色2”；再列假设：“温度过低或模型分布过尖”；最后说明区分实验：“固定参数与前缀改变温度，在开发集比较”。这个实验应归入后续开发，不能悄悄重新选当前最终结果。

按样本子组汇总有助于发现集中问题，但子组应有含义，如横条、竖条、方框，且报告数量。只剩1张样本的子组不支持稳定的群体结论。不要在几十种切法中寻找一个惊艳差异再当作预先假设；把事后切片标为探索性并等待新数据检验。

写结论时使用证据链：一个结论对应结果表的行、图的点或样本ID。可以写“该配置在本固定测试集的新域收益为0.66、旧域遗忘0.12”；不能写“LoRA不会遗忘”或“小模型解决知识迁移”。失败与负结果应说明已排查什么、仍不能判断什么，不用猜测填满因果故事。

观察和解释分两栏

  1. 观察：某固定前缀的补全出现重复颜色；teacher forcing损失却不高。

  2. 假设一：自由生成偏离训练历史后积累错误；假设二：采样温度导致分布过尖。

  3. 可区分操作：在开发样本上分别比较真实历史喂入和自由历史，并固定其他条件调整温度。

  4. 尚未做区分实验前，仅报告观察与待检验原因。

列出合理原因不等于原因已被证明。

"""Aggregate fabricated final-test token losses; no actual test set is read."""
# STEP 1
# id, token_count, base_A_sum, adapted_A_sum, base_B_sum, adapted_B_sum
rows = [("gA",2,.8,1.2,3.2,2.2), ("gB",8,3.2,4.0,12.8,7.2)]
assert len({row[0] for row in rows}) == len(rows)
assert all(row[1] > 0 for row in rows)
frozen, already_evaluated = True, False

# STEP 2
def evaluate(frozen, already_evaluated, rows):
    if not frozen or already_evaluated:
        raise ValueError("freeze first; do not reopen the final test to select a model")
    tokens = sum(r[1] for r in rows)
    losses = [sum(r[column] for r in rows) / tokens for column in range(2,6)]
    return losses, True

# STEP 3
losses, already_evaluated = evaluate(frozen, already_evaluated, rows)
base_a, adapt_a, base_b, adapt_b = losses
image_average_b = sum(r[5]/r[1] for r in rows)/len(rows)
blocked = False
try:
    evaluate(frozen, already_evaluated, rows)
except ValueError:
    blocked = True
assert blocked

# STEP 4
print("FABRICATED FINAL TABLE; no actual final test opened")
print(f"tokens={sum(r[1] for r in rows)} base_A={base_a:.6f} adapt_A={adapt_a:.6f}")
print(f"base_B={base_b:.6f} adapt_B={adapt_b:.6f}")
print(f"gain={base_b-adapt_b:.6f} forgetting={adapt_a-base_a:.6f}")
print(f"image_average_B={image_average_b:.6f} token_average_B={adapt_b:.6f}")
print("repeat_gate=PASS (in-memory demonstration only)")

C++

// Aggregate fabricated final-test token losses; no actual test set is read.
#include <array>
#include <cassert>
#include <iomanip>
#include <iostream>
#include <set>
#include <stdexcept>
#include <string>
#include <vector>
// STEP 1
struct Row { std::string id; int tokens; std::array<double,4> sums; };
// STEP 2
std::array<double,4> evaluate(bool frozen,bool& already_evaluated,const std::vector<Row>& rows) {
    if(!frozen || already_evaluated) throw std::invalid_argument("freeze first; no reselection");
    int tokens=0; std::array<double,4> losses{};
    for(const auto& r:rows) { tokens+=r.tokens; for(int i=0;i<4;++i) losses[i]+=r.sums[i]; }
    assert(tokens>0); for(double& loss:losses) loss/=tokens;
    already_evaluated=true; return losses;
}
int main() {
    const std::vector<Row> rows{{"gA",2,{{.8,1.2,3.2,2.2}}},{"gB",8,{{3.2,4.0,12.8,7.2}}}};
    std::set<std::string> ids;
    for(const auto& r:rows) { assert(r.tokens>0); ids.insert(r.id); } assert(ids.size()==rows.size());
    const bool frozen=true; bool already_evaluated=false;
    // STEP 3
    const auto loss=evaluate(frozen,already_evaluated,rows);
    double image_average_b=0; int tokens=0;
    for(const auto& r:rows) { image_average_b+=r.sums[3]/r.tokens; tokens+=r.tokens; }
    image_average_b/=rows.size(); bool blocked=false;
    try { evaluate(frozen,already_evaluated,rows); } catch(const std::invalid_argument&) { blocked=true; }
    assert(blocked);
    // STEP 4
    std::cout<<std::fixed<<std::setprecision(6);
    std::cout<<"FABRICATED FINAL TABLE; no actual final test opened\n";
    std::cout<<"tokens="<<tokens<<" base_A="<<loss[0]<<" adapt_A="<<loss[1]<<'\n';
    std::cout<<"base_B="<<loss[2]<<" adapt_B="<<loss[3]<<'\n';
    std::cout<<"gain="<<loss[2]-loss[3]<<" forgetting="<<loss[1]-loss[0]<<'\n';
    std::cout<<"image_average_B="<<image_average_b<<" token_average_B="<<loss[3]<<'\n';
    std::cout<<"repeat_gate=PASS (in-memory demonstration only)\n";
}

逐步解释

保存总和与分母

每行记录ID、token数及四个总损失，避免只有一个批次平均数。检查来源ID唯一、token数为正；真实项目还要校验清单完整性。

自查：说出2.2表示总损失而非每token平均。

评价门控与汇总

函数先检查冻结及未使用状态，再累加列并除总token。Python返回更新后的布尔值，C++用引用修改它，展示两种状态传递方式。

自查：若already_evaluated=True，应拒绝。

同时核对两种平均

计算等图平均作为对照，再故意第二次调用并捕获预期异常。try/except与C++try/catch处理预期拒绝，不吞掉任意未知错误。

自查：为什么1.00与0.94都可计算但不能混称同一指标？

结果附测量边界

打印四项损失、差值和门控范围。虚构表没有实际打开测试；进程内状态演示不是持久审计。

自查：把gB的token数改动时，也要同步修改总损失或解释新的数据含义。

练习与参考答案

练习1

基础：两批token数分别10、30，平均损失分别2、1，整体token平均是多少？

提示：

先还原每批总损失。

参考：

总损失10×2+30×1=50，总token40，平均1.25；直接(2+1)/2=1.5是等批平均，除非协议规定等批权重，否则不是目标指标。

练习2

实践：B损失下降而补全经常断裂，怎样写分析？

提示：

分别说明teacher forcing与自由生成。

参考：

报告两种观察；提出生成历史偏移、采样规则或局部结构约束不足等假设；在后续开发中设计单因素对照。不要把低损失等同于好图片，也不要未经验证断言唯一原因。

练习3

迁移：最终测试某子组只有2张，表现比另一方法好，能下什么结论？

提示：

限定观察数量与事后分析性质。

参考：

可准确描述这2张样本上的结果，不能推广到该子组总体。保留ID、预测与子组定义；若发现来自事后切片，应标为探索性，下一轮用新独立样本验证。

开放讲解题

为什么测试后不能依据错误重新挑学习率，再沿用原最终分数？

测试信息参与选择后，其独立评估角色受到破坏。继续研究可以，但应保留旧报告、创建新开发版本并另备独立最终数据。

怎样把一项结论做成可回查证据？

注明配置与模型ID、数据版本与用途、指标定义、结果表行和样本ID，区分观察和假设；让读者从原始数值重新算出差值。

交付物

  • 冻结后A/B最终结果表、实际资源及完整评价记录
  • 全部固定前缀补全与逐样本错误分类
  • 报告中的结论—证据对应表和探索性分析标记

验收标准

  • 四项损失的计分范围、对数底与分母一致
  • 最终测试结果没有回流选择配置
  • 每项主要结论有结果或样本依据；未验证原因标为假设
