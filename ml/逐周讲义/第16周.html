从概率到补全：温度、采样与项目B基础交付

011 预测分布之后，还需要一个选择规则

模型输出下一token的logits，softmax得到概率，但概率本身不是一个token。贪心选择最大概率项；随机采样按分布抽取一个ID。二者回答不同问题：贪心容易重复或集中在常见模式，采样保留多样性但可能选择低概率错误。不能用“随机更有创造力”代替具体结果。

温度T在softmax前除logits。T小于1时差异被放大，分布更尖锐；T大于1时差异被缩小，分布更平缓。正温度不会改变logit排序，所以贪心argmax不随T改变，但采样概率改变。T必须大于0；T=0作为贪心是某些接口的约定，本页直接拒绝0，避免除零。

温度不是训练模型的新知识来源。提高T只能重新分配现有分数的概率，不能修复错误词表、因果泄漏或没有学到结构的模型。比较温度必须使用同一模型检查点、同一前缀和约定随机性；本页使用预先给定的均匀随机数序列，使Python和C++选择完全可核对，避免不同随机数库的实现差异。

022 用累计概率实现一次采样

抽一个位于[0,1)的均匀数u，把各类别概率依次累加，选第一个累计值严格大于u的类别。这叫逆累计分布采样。每段区间的长度就是该类别概率，所以均匀数落入某段的频率与概率一致。浮点加法可能让最后累计值略小于1，因此实现保留返回最后类别的兜底，但不应靠它掩盖未归一化概率。

自回归生成维护一个可增长序列。每一步用当前前缀前向，只取最后位置的logits，采样一个token并追加，再进入下一步。不能一次取所有位置的最大概率拼成未来图像，因为后续位置的上下文应包含已生成结果。最初给定前缀必须完整保留，不允许模型回改其中的像素。

本页程序是一个固定的三状态转移模型，下一分布只取决于最后一个token，不是Transformer，也没有训练图像。它仍能完整展示生成循环、累计采样、温度与teacher-forced评分。Pythonlist.append和C++vector.push_back做相同的“追加一个token”；复制prefix避免不同温度运行相互污染。

  2. u=0.8落在第二段，因此选类别1。

采样不仅改变当前token，还会通过新上下文改变之后的选择。

033 真实项目的240像素前缀与160像素补全

使用第15周按开发规则选定的检查点，切换eval并关闭梯度。对每张20×20图按原扫描顺序取前240个ID，也就是前12行；生成160个ID组成后8行，总长度400。第一次把完整前缀送入模型，取logits[:,−1,:]得到下一颜色分布，采样后连接，再次前向。初学实现可以每步重算全前缀，先保证正确，再考虑KV cache。

位置容量必须容纳最终400个token。检查生成ID都在0…166内，prefix与输出前240项逐项一致，最终长度严格400，颜色映射还原后是20×20图。若使用8×8合成替代，事先约定例如前40像素补24像素，并把位置容量、mask和图像还原同步修改，报告不与官方400像素评分混比。

在查看生成结果之前固定16个开发集样本ID，保存前缀、真实完整图和生成图。每个配置都展示全部16张，按同一顺序排成4×4网格；真实后缀可以并列用于观察，但生成函数不能读取它。固定三个温度如0.5、1、1.5和采样种子，展示所有组合或预先规定的主配置，不从大量采样中挑最好看的一张。

同时跑训练颜色频率基线的同长度补全，保留相同前缀和随机种子约定。频率基线不利用形状上下文，因此可帮助判断小Transformer是否学到超过全局颜色比例的结构。若基线或模型重复、颜色坍缩、断裂，都完整展示，并记录失败定义。

检查生成无泄漏时，应把真实后缀删去或替换成任意值，保持前缀不变，确认生成输出在固定随机种子下不变。第14周未来token扰动检查作用于模型前向，这里检查整套生成函数和数据流程；两者不能互相代替。

044 基础版交付：把预测与生成分开报告

Teacher-forced开发交叉熵衡量模型在真实前缀下对下一token的预测。自由生成质量还受自身错误形成的新上下文、采样规则和整体结构影响。一个模型平均loss较低，仍可能在某些前缀上产生重复或形状破坏。因此同时保存开发损失、完整生成网格、采样配置和失败描述，不把其中任一项当作全部质量。

HW4的官方FID与PDR依赖具体评估流程，PDR还涉及助教分类器。主线不要求为了过关额外训练一个评价模型，也不把小样本网格主观印象当官方分数。可以记录颜色分布、重复后缀比例等透明辅助统计，但要承认它们不等于视觉语义质量。

基础版通过条件是编码还原正确、偏移与mask正确、小样本训练能学习、开发基线可比、固定样本完整展示、代码配置和检查点可回查。若结果不优于频率基线，先查实现和训练预算，并如实提交定位记录；不为了进入LoRA阶段隐藏失败。第17周适配需要保留明确基础检查点，因此基础训练尚未可靠时应补学。

本周复述跨章节链条：从一张图到ID序列，从序列到嵌入，从Q/K/V与mask到上下文，从logits到损失与梯度，再从检查点到逐token采样。选择任意一个中间数组说明形状、含义、能看到的数据、错误时的表现。能讲清这条链比背出Transformer结构名称更重要。

Python

"""Fixed random uniforms make sampling comparable across Python and C++."""
import math
# STEP 1
logits = [[2.,1.,0.],[0.,2.,1.],[1.,0.,2.]]
prefix = [0,1]
uniforms = [.1,.8,.55,.95,.3,.65]
def probabilities(last,t):
    if t<=0:
        raise ValueError('temperature must be positive')
    scaled = [z/t for z in logits[last]]
    values = [math.exp(z-max(scaled)) for z in scaled]
    return [v/sum(values) for v in values]
# STEP 2
def sample(p,u):
    total = 0.
    for i,v in enumerate(p):
        total += v
        if u<total:
            return i
    return len(p)-1
def generate(t):
    sequence = prefix.copy()
    for u in uniforms:
        sequence.append(sample(probabilities(sequence[-1],t),u))
    return sequence
# STEP 3
for t in (.5,1.,2.):
    p = probabilities(0,t)
    entropy = -sum(v*math.log(v) for v in p)
    sequence = generate(t)
    print(f'T={t:.1f} prob0='+' '.join(f'{v:.6f}' for v in p)+f' entropy={entropy:.6f}')
    print('completion='+' '.join(map(str,sequence)))
    assert sequence[:len(prefix)] == prefix
# STEP 4
truth = [0,1,2,0]
teacher_nll = -sum(math.log(probabilities(truth[i],1.)[truth[i+1]]) for i in range(len(truth)-1))/(len(truth)-1)
print(f'teacher_forced_nll={teacher_nll:.6f}')
assert len(generate(1.))==len(prefix)+len(uniforms)
print('prefix_and_length_check=True trained_image_model=False')

逐步解释

分数变成温度概率

logits是3×3固定转移表；按最后token选一行，除温度、减最大值、指数归一化。prefix和uniforms固定，便于跨语言一致。

自查：手算T=1、last=0的一行概率与累计区间。

一次抽样与生成循环

sample累加概率并选择区间；generate先复制prefix，再对每个预定均匀数追加一个token。当前最后token随循环变化。

自查：指出如果每轮都用prefix[-1]而不是sequence[-1]会失去什么依赖。

三个温度完整展示

按T=0.5、1、2打印概率、熵和完整补全序列，不选择最好结果。断言前缀保持不变。

开放讲解题

温度能修复因果泄漏吗？

不能。温度只改变logits到概率的映射，泄漏发生在数据或计算路径。必须修复目标shift、mask及生成函数输入，并重新训练和评估受影响模型。

什么时候基础版可进入适配研究？

当编码、偏移、mask、训练和评估流程已核对，已有可回查基础检查点和开发结果，生成展示覆盖固定样本且失败如实记录。只有一份漂亮样图或局部采样程序不够。
