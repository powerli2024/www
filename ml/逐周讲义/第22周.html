重复实验：先配对，再谈均值与不确定性

01随机性来自哪里，种子又控制了什么

适配过程中低秩初始化、批次顺序、dropout等会影响结果；基础模型本身也受到预训练随机性的影响。本主线固定一个基础检查点，只重复适配种子，所以测到的是这个基础模型下的适配变化。即使3次都同方向，也没有覆盖换基础模型、换数据划分或换变换规则的变化。

配对是让两个方法的比较尽可能共享背景条件。种子11下全量与LoRA都从同一基础文件出发，使用同一B训练清单和预先生成的批次顺序；种子22、33同理。各方法内部随机调用数量可能不同，因此只调用同一个seed值不保证批次完全一致；最好保存实际批次索引或数据加载器顺序。

正式重复使用已冻结的配置，不在每个种子上再挑各自最好的学习率。否则你测到的是重新搜索后的最好成绩，还额外增加了预算。重复中若出现数值错误，应记录种子、步数、日志和处理规则，不能反复换种子直到得到三个漂亮结果。

以每个种子为一对，先算LoRA减全量的差，再求平均。这样可以观察同一背景条件下的相对变化。如果直接混合所有图像的token当成独立训练重复，会夸大证据量：一百万token不是一百万次独立训练。统计单位必须与问题对应。

一起算一个例子

三对训练怎样排列

  1. 配对11：同base-v1、同批次顺序order11，分别跑全量和LoRA。

  2. 配对22、33分别使用自己的顺序，但每对内部共享。

  3. 结果表每行一个seed，同时列两方法收益与遗忘；不要把方法A的11号和方法B的33号随便相减。

配对使比较含义清楚，也让差异的来源更容易定位。

02均值描述中心，标准差描述波动

三次相对收益差为−0.10、−0.05、−0.07。平均−0.073333说明这三对完成运行中LoRA平均收益比全量少0.073333。负号不代表模型没有学习，而是相对另一种方法学得少；需要结合两者各自收益与不适配基线看。

样本标准差先计算每个差值到平均的距离，平方求和，除以n−1，再开平方。这里约0.025166，描述三次差值的离散程度；它不是均值的标准误，也不是95%置信区间。只有三次时，分布形状、异常值和缺失运行都很难判断，本课程默认报告原始点、均值、标准差或范围。

收益差与遗忘差分别算，不能一列混合。三对遗忘差为−0.13、−0.08、−0.16，平均−0.123333；负号表示LoRA比全量少遗忘。教学数据中出现“收益更少、遗忘也更少”的取舍，这与论文问题相似，但数据是人为构造，不能作为经验结论。

点击放大

先计算成对差，再汇总中心与样本波动。

逐个认识符号

  • d_i：第i个配对种子中LoRA指标减全量指标

  • n：完整配对数，此例为3

  • d̄：成对差的均值

  • s_d：样本标准差，要求n≥2

一起算一个例子

手算收益差的样本标准差

  1. 均值=(-0.10-0.05-0.07)/3=-0.073333。

  2. 偏差约为−0.026667、0.023333、0.003333。平方和约0.001266667。

  3. 除以n−1=2得0.000633333，开平方约0.025166。

  4. 范围为[−0.10,−0.05]；本次所有完成配对都为负。

原始点、均值和范围一起报告，比只写“显著更少”更忠实。

03缺失与失败不能悄悄从实验中消失

程序额外记录计划的第4个种子44失败，所以显示requested=4、complete=3、failed=1。均值只针对三个完整配对，并明确这种条件。若失败更容易发生在某种方法或困难批次，完整配对的均值可能有选择偏差；不能假设失败一定随机。失败次数和原因是结果的一部分。

按协议先诊断失败是否来自实现问题、资源限制或方法数值不稳定。实现错误需要修复版本后重跑受影响部分；资源超限可作为固定预算下的失败；外部断电可以按事先记录的恢复规则复跑同种子。任何重跑都保留前一次状态，不能把它当从未发生。

画图时每个种子一个点或一条配对连线，标注方法、收益、遗忘和失败。均值旁的误差条说明是标准差还是其他量；不写含糊的“误差”。固定同一基础检查点时，应在图注写明，这能阻止读者误以为误差条覆盖全部训练不确定性。

本周只用开发集检查重复与生成行为，最终测试仍封存。若观察到配置不稳定而决定改学习率，应开启新开发版本，完成后重新冻结；不要先用测试替自己挑稳定的种子。至少三次是学习预算的起点，不是统计保证。

Python与C++机制示例

下面的小程序验证关键机制；完整项目须按本周交付要求另行完成。

Python

"""Paired synthetic run summaries. Three completed pairs, one failed pair."""
import math

# STEP 1
rows = [(11,.62,.52,.21,.08), (22,.55,.50,.18,.10), (33,.68,.61,.25,.09)]
failed_seeds = [44]
# seed, full_gain, lora_gain, full_forgetting, lora_forgetting
assert len({row[0] for row in rows}) == len(rows)
assert not ({row[0] for row in rows} & set(failed_seeds))

# STEP 2
def mean_std(values):
    assert len(values) >= 2
    mean = sum(values) / len(values)
    variance = sum((value - mean) ** 2 for value in values) / (len(values) - 1)
    return mean, math.sqrt(variance)

# STEP 3
gain_differences = [r[2] - r[1] for r in rows]
forgetting_differences = [r[4] - r[3] for r in rows]
gain_mean, gain_std = mean_std(gain_differences)
forget_mean, forget_std = mean_std(forgetting_differences)
assert gain_mean < 0 and forget_mean < 0

# STEP 4
print("SYNTHETIC PAIRS; conditional on completed runs")
print(f"requested={len(rows)+len(failed_seeds)} complete={len(rows)} failed={len(failed_seeds)}")
print(f"gain_LoRA_minus_full_mean={gain_mean:.6f} sample_std={gain_std:.6f}")
print(f"forget_LoRA_minus_full_mean={forget_mean:.6f} sample_std={forget_std:.6f}")
print("significance_claim=False base_checkpoint_variation_tested=False")

C++

// Paired synthetic run summaries. Three completed pairs, one failed pair.
#include <array>
#include <cassert>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <set>
#include <vector>
// STEP 1
struct Row { int seed; double full_gain,lora_gain,full_forgetting,lora_forgetting; };
// STEP 2
std::array<double,2> mean_std(const std::vector<double>& values) {
    assert(values.size()>=2); double total=0;
    for(double v:values) total+=v;
    const double mean=total/values.size(); double variance=0;
    for(double v:values) variance+=(v-mean)*(v-mean);
    variance/=values.size()-1;
    return {mean,std::sqrt(variance)};
}
int main() {
    const std::vector<Row> rows{{11,.62,.52,.21,.08},{22,.55,.50,.18,.10},{33,.68,.61,.25,.09}};
    const std::set<int> failed_seeds{44}; std::set<int> completed_seeds;
    for(const auto& r:rows) { assert(!failed_seeds.count(r.seed)); completed_seeds.insert(r.seed); }
    assert(completed_seeds.size()==rows.size());
    // STEP 3
    std::vector<double> gain_differences,forgetting_differences;
    for(const auto& r:rows) {
        gain_differences.push_back(r.lora_gain-r.full_gain);
        forgetting_differences.push_back(r.lora_forgetting-r.full_forgetting);
    }
    const auto gain=mean_std(gain_differences), forget=mean_std(forgetting_differences);
    assert(gain[0]<0 && forget[0]<0);
    // STEP 4
    std::cout<<std::fixed<<std::setprecision(6);
    std::cout<<"SYNTHETIC PAIRS; conditional on completed runs\n";
    std::cout<<"requested="<<rows.size()+failed_seeds.size()<<" complete="<<rows.size()<<" failed="<<failed_seeds.size()<<'\n';
    std::cout<<"gain_LoRA_minus_full_mean="<<gain[0]<<" sample_std="<<gain[1]<<'\n';
    std::cout<<"forget_LoRA_minus_full_mean="<<forget[0]<<" sample_std="<<forget[1]<<'\n';
    std::cout<<"significance_claim=False base_checkpoint_variation_tested=False\n";
}

逐步解释

用种子组织成对记录

每行同时包含两方法的收益与遗忘，避免排序错配。集合检查种子唯一且与失败列表不重叠。元组和C++结构体只是两种存储方式。

自查：逐行指出seed=22的收益差为−0.05。

实现样本标准差

Python列表与C++vector都先求均值，再累加平方偏差，最后除以n−1开方。n≥2断言避免没有波动估计的情况。

自查：解释为什么此处不能除以3冒充样本标准差。

两种差分别汇总

收益用lora_gain−full_gain，遗忘用lora_forgetting−full_forgetting。两列都为负的含义不同：一列少学习，另一列少退化。

自查：手算两列均值的方向。

报告完成条件与未覆盖变化

输出请求、完成、失败数量，且声明没有作显著性结论、没有测试基础检查点变化。这些字段防止统计数字脱离运行事实。

自查：为何4次计划不能写成4次完整比较？

练习1

基础：差值为0.1、0.1、0.1，均值与样本标准差是多少？

提示：

所有点到均值距离为零。

参考：

均值0.1、标准差0。这只表示这三次记录相同，不表示未知任务或其他基础检查点下必然相同；还要排查是否误复用了相同输出。

练习2

实践：差值为−0.1、0、0.1，计算均值与标准差。

提示：

平方和0.02，除以2。

参考：

均值0，样本标准差sqrt(0.01)=0.1。均值零不能解释成每次都没有差异；三个原始点呈现方向变化，应该一起报告。

练习3

迁移：某方法失败一半，却只对成功结果报很低的平均损失，缺了什么？

提示：

先问分母是谁。

参考：

缺少请求/完成/失败数、失败机制及条件性说明。成功条件下的低损失不等于整个运行流程可靠。不能随意补损失值，应按协议报告失败与有效结果，必要时另做稳定性分析。

开放讲解题

为什么要先算差再求均值？

它保持同一背景条件下两方法的一对一比较，并允许直接分析相对效果的波动；只看各自均值会隐藏配对关系。

怎样写一段不过度外推的结果？

在固定基础检查点和本数据划分上，三个完整配对的收益差均值为某值、标准差某值，另有某次失败；结果描述本设定的取舍，不覆盖预训练种子或其他任务。

交付物

  • 至少3个完整配对运行的原始记录及所有失败状态
  • 成对差值、均值、标准差或范围的可复算表
  • 收益—遗忘图及清楚说明重复范围的图注

验收标准

  • 每对共享同一基础检查点和可查批次设置
  • 平均与标准差能从原始行重新算出，缺失未填成零
  • 没有把完成条件下结果或3次重复外推为普遍定律
