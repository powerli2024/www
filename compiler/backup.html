第1章　编译概述

这一章回答三个问题：编译程序是什么、它分几步做、这些步骤如何组织成可维护的系统。读完后你应能画出编译程序的流水线，并解释每一步的产物为什么是下一边的输入。

1.1　翻译程序与编译程序

素材位置：第1章 2026.pdf，pp.23–26

关键概念：编译程序（compiler）与翻译程序（translator）

一句话定义：翻译程序把一种语言写的程序译成等价的另一种语言的程序；编译程序是其中专门把高级语言源程序译成等价的机器语言或汇编语言目标程序的那一类。

边界与适用条件：

  • 源语言与目标语言可以是任意一对语言；「编译程序」这个名称把目标语言限定为机器语言或汇编语言（p.23–24）。
  • 编译只负责产出目标程序，不负责运行；运行由运行系统（操作系统、动态链接器等）承担（p.25–26）。
  • 素材给出两种运行阶段模型：第一种直接「编译 → 运行」，第二种在中间多出一个汇编阶段（p.25–26）。

不是什么：编译程序不等于解释器：解释器不产出等价目标程序，而是边翻译边执行（见 §1.2）。也不等于汇编器：汇编器只做「汇编语言 → 机器语言」，是编译流水线中的一道工序（p.6 的 as）。

表征：

  • 表征一：逐字对照：C 程序 printf("hello, world！\n") 与目标形态 00 00 10 10… 是同一程序的两个语言版本（p.23）。
  • 表征二：两阶段模型：第一种情况：源程序 → 编译程序 → 机器语言目标程序 →（运行阶段）初始数据 + 运行系统 → 结果；第二种情况在编译与运行之间插入「汇编阶段」（p.25–26）。

可检验动作：拿 p.6 的四个命令各跑一步，判断执行完该命令后程序处于「源语言」还是「目标语言」一侧，并说出第二种情况里汇编阶段的位置。

复现：§1.2 用它区分编译与解释；§1.6 用它理解前端/后端；§3.7 的 Scanner 就是编译阶段第一道工序的可执行形态。

素材原文（p.23）：翻译程序是将一种语言所写的程序译成等价的另一种语言的程序。源语言一侧是高级语言程序，目标语言一侧是机器语言程序，中间是翻译程序。

素材原文（p.24）：编译程序是一种翻译程序，它将高级语言所写的源程序翻译成等价的机器语言或汇编语言的目标程序。可见「编译程序 ⊂ 翻译程序」，限制条件落在目标语言上。

【素材边界】素材只给出 hello world 的对照与产物统计，没有提供源程序文件本身；§1.2 的 sum.c / sum.py 同样只给了命令与结果。

1.2　编译与解释：同一条流水线的两种用法

素材位置：第1章 2026.pdf，pp.5–7

关键概念：编译与解释（compile vs interpret）

一句话定义：编译在执行前把整个源程序译成目标程序；解释在运行时逐句翻译并执行，不预先生成完整的目标程序。

边界与适用条件：

  • 差异可以从三处观察：产物（.s/.o/可执行文件 vs 无独立产物）、时序（运行前 vs 运行中）、错误暴露时机（p.6–7）。
  • 素材的速度数据是特定环境实测：C -O2 为 0.0034 s（基准 1.0），C -O0 为 0.0150 s（4.4 倍），Python 内置 sum 0.0709 s（20.9 倍），Python 逐句解释 0.2619 s（77.1 倍）——只能说明本例，不能外推为语言优劣结论。

不是什么：不是「编译型语言没有运行时」，也不是「解释型语言不做语法检查」。素材的两段代码只说明错误被发现的时机不同，不说明检查能力的强弱。

表征：

  • 表征一：五步命令与产物：gcc -E → -S → -c → 链接 → 装载执行，五道工序各自有明确的「停在哪一步之后」与产物（见下表）。
  • 表征二：耗时与错误时机：同一累加 1~n（缺省 5000000）的四种执行方式耗时相差 77 倍；而 int x = "hello"; 与 x = x + 'abc' 的错误出现在完全不同的阶段。

可检验动作：用下表回答：停在 .i / .s / .o / 可执行文件之后，各发生了什么？再判断两段代码的错误分别出现在编译期还是运行期。

复现：§1.3 把「编译阶段」内部再拆成五步；§3.7 的 Scanner 是这五步中第一步的代码形态。

1.3　编译过程的五个阶段

素材位置：第1章 2026.pdf，pp.27–30、38–39

关键概念：编译过程的五个阶段（five phases）

一句话定义：编译被拆成五个职责单一的阶段：词法分析 → 语法分析 → 语义分析及中间代码生成 → 代码优化 → 目标代码生成。

边界与适用条件：

  • 这是逻辑分解，不等于「五遍」（见 §1.6）。
  • 每个阶段都绑定一条原则与一种描述工具：词法/词法规则/有限自动机；语法/语法规则/上下文无关文法；语义/语义规则/属性文法；优化/程序等价变换规则；目标代码/硬件结构与指令含义（p.28–34）。
  • 表格管理与错误处理不单独成阶段，它们贯穿所有阶段（p.37）。

不是什么：不是「语义分析只负责查错」：它还按语义规则做初步翻译并产出中间代码（四元式、三元式或树，p.30）。也不是「五个阶段必须各自独立成程序」：p.38 的结构图中它们是流水线上的五个部件。

表征：

  • 表征一：把英文译成中文的类比：识别句中一个个单词（词法）→ 分析句子语法结构（语法）→ 按含义初步翻译（语义与中间代码）→ 修饰译文（优化）→ 写出最后译文（目标代码）（p.27）。
  • 表征二：一句赋值语句的四元式：Z := X + 0.618 * Y 生成三条四元式：先乘、再（乘）+、最后赋值（p.30）。
  • 表征三：一条语句的全流程：position := init + rate * 60 从单词串一路变成 5 条浮点指令（p.39），见下表。

可检验动作：把 Z:=X+0.618*Y 的三条四元式写出来，并说明为什么 RESULT 列是 T1、T2、Z 三个不同名字。

复现：第 2 章为语法分析提供文法与推导工具；第 3 章把第一阶段（词法分析）完整展开；§3.2 的有限自动机正是 p.28 提到的描述工具。

1.4　代码优化：等价变换换效率

素材位置：第1章 2026.pdf，pp.31–33

关键概念：代码优化（code optimization）

一句话定义：在保持语义等价的前提下变换中间代码，使最终目标代码更高效。素材的例子通过把循环不变量提到循环外、并把乘法削弱为加法，使 200 次乘法变为 0 次、400 次加法变为 301 次。

边界与适用条件：

  • 前提是「等价变换」：优化不能改变程序的可观察行为。
  • 作用对象是中间代码，不是源程序也不是最终机器码；目标机相关的优化属于后端（p.42）。
  • 素材只给出一个循环局部优化的完整前后对照，没有展开全局优化、寄存器分配等理论。
  • 从 400→301 的推导依赖一个隐含前提：I、J 在循环体内不被修改。素材未明说，此处标为推断。

不是什么：不是任何改写都叫优化；也不等于「把程序写短」。若改写改变了语义，就不是优化而是错误变换。

表征：

1.6　编译程序的结构：阶段、遍与前端/后端

2.1　字母表、符号串与闭包

素材位置：第2章 2026.pdf，pp.9–16；第2章 2026（文明）.pdf，pp.7–20

关键概念：字母表、符号串、闭包 A* 与正闭包 A+

一句话定义：字母表是元素的非空有穷集合 Σ，符号串是其中符号的有穷序列；闭包 A* 把 A 的 0 次、1 次、2 次……连接结果全部收进一个集合（含空串 ε），正闭包 A+ 则去掉 0 次幂那一项。

边界与适用条件：

  • A0 = {ε}，不是 {1}； A* = A0 ∪ A1 ∪ A2 ∪ …； A+ = A1 ∪ A2 ∪ …； 因此 A* = {ε} ∪ A+（p.11；文明版 p.19）。
  • ε 是长度 0 的符号串，{ε} 是只含一个元素的集合，Φ 是不含任何元素的空集——三者不能混用（文明版 p.14）。
  • Σ* 表示 Σ 上所有字的全体（含 ε）；Σ+ 不含 ε（p.9、p.12）。

不是什么：闭包不是「把集合里的元素各重复若干次」的模糊说法，必须按 A^n 的集合并来理解；A* 也不是「无限长串的集合」，其中每个串仍然有穷。

表征：

  • 表征一：枚举：设 Σ={a,b}，则 Σ* = {ε, a, b, aa, ab, ba, bb, aaa, …}（p.9）。设 A={a,aa}，则 A* = {ε, a, aa, aaa, …}，A+ = {a, aa, aaa, …}（p.11）。
  • 表征二：集合运算：连接 xy 把两个串接起来；集合乘积 AB={xy | x∈A, y∈B}；A 的 n 次幂是 n 个 A 的乘积，A0={ε}（p.10–11）。
  • 表征三：无穷集合的有穷描述：Σ+ 有无穷多个串，但可用四条规则 A→0 | 1 | A0 | A1 生成（p.15）：有穷规则描述无穷集合，靠的是递归。

可检验动作：取 A={a,aa}，手算 A0、A1、A2、A3 与 A*、A+ 的前五项，检查哪一个含 ε。

复现：§2.2 的四元组中 (VT∪VN)* 就是这里的闭包；§3.2 正规式的 (e1)* 表示 L(e1) 的闭包，同名同义。

定义（p.9；文明版 p.7–10）：字母表 Alphabet 是元素的非空有穷集合，记作 Σ；字母表中的元素叫符号（字符）；由 Σ 中符号构成的有穷序列叫符号串（字）；不含任何符号的序列叫空符号串，记 ε。

2.2　文法的形式定义与它定义的语言

素材位置：第2章 2026.pdf，pp.18–24；第2章 2026（文明）.pdf，pp.29–63

关键概念：上下文无关文法（context-free grammar）的四元组

一句话定义：上下文无关文法是一个四元组 G=(VT, VN, S, P)：VT 是非空终结符集，VN 是非空非终结符集，S∈VN 是开始符号，P 是有限产生式集，每条形如 A→α（A∈VN，α∈(VT∪VN)*）；由 S 推导出的、只含终结符的串全体就是它定义的语言。

边界与适用条件：

  • VT 与 VN 非空且不相交（素材 p.19 的公式丢了交集符号，此处按上下文补全，标为推断）。
  • 开始符号 S 至少必须在某个产生式的左部出现一次（p.19）。
  • α 可以是 ε，因此上下文无关文法允许 A→ε 这类产生式（素材中出现 B→ε 的例子，p.16 语法、p.22 语法）。
  • 一个语言可以有多个文法；但给定文法，其语言被唯一确定（文明版 p.63）。

不是什么：文法不是语言：语言是句子的集合（可能无穷），文法只是有穷条规则。文法也不等于「程序的语法」，它描述的是语言的结构，不含语义。

表征：

  • 表征一：自然语言例子：HUST celebrates the 70th anniversary 的规则集（p.7）：<句子>→<主语><谓语><宾语>、<名词>→HUST 等，逐步替换后得到原句。
  • 表征二：表达式文法：G[E]：E → i | E+E | E*E | (E)，四元组为 ({i,+,*,(,)}, {E}, E, P)（p.20–21）。缩写 A→α1|α2|…|αn 表示 n 条同左部产生式。
  • 表征三：推导链：E ⇒ (E) ⇒ (E+E) ⇒ (i+E) ⇒ (i+i)，所以 (i+i) 是 G[E] 的句子（p.22）。

可检验动作：用 G[E] 推出 (i*i+i)，再用 G1[A]：A→c | Ab 推出它生成的全部串，写出 L(G1)。

复现：§2.4 的短语/句柄、§2.6 的四型分类、§3.3 的正规文法都是这个四元组的特例或加限制版本。

规则（产生式）是一个符号与一个符号串的有序对 (A, β)，写作 A→β，也可写作 A::=β（巴科斯范式 BNF）（p.18）。

2.3　推导、归约与最左/最右推导

素材位置：第2章 2026.pdf，pp.22–26；第2章 2026（文明）.pdf，pp.48–72

关键概念：推导（derivation）与归约（reduction）

一句话定义：推导是用产生式把句型中的非终结符替换成右部；归约是反向替换。每一步都替换最左非终结符叫最左推导，替换最右非终结符叫最右推导（又称规范推导）。

边界与适用条件：

  • 记号分层：⇒ 是一步直接推导；⇒* 是 0 步或若干步；⇒+ 是 1 步或若干步（p.22）。
  • 最右推导的逆过程称为最左归约，也称规范归约（文明版 p.70）。
  • 推导与归约只是方向不同：xAy ⇒ xαy 是推导，xαy ⇒ xAy 是归约（p.26）。

不是什么：一个句子的推导序列通常不唯一，这并不等于文法二义（§2.5）；只有「最左推导不唯一」或「最右推导不唯一」才是二义性的判定依据（文明版 p.95）。

表征：

  • 表征一：同一句子的两条推导：E⇒E+E⇒i+E⇒i+i 与 E⇒E+E⇒E+i⇒i+i（p.25）。两条都对，只是替换顺序不同。
  • 表征二：最左/最右对照：G[N]：N→ND | D，D→0…9，句子 0127 的最左推导 N⇒ND⇒N7⇒ND7⇒N27⇒ND27⇒N127⇒D127⇒0127；最右推导 N⇒ND⇒NDD⇒NDDD⇒DDDD⇒0DDD⇒01DD⇒012D⇒0127（p.52）。

可检验动作：对 0127 分别写出最左与最右推导，并判断「0127」是句型还是句子。

复现：§2.4 句柄就是「规范归约」每一步要归约的对象；§2.5 用「两个不同最左推导」判定二义性；§3.7 的分析程序按状态逐步前进，本质是在模拟推导。

直接推导（p.22）：称 αAβ 直接推出 αγβ（记 αAβ⇒αγβ），仅当 A→γ 是一条产生式，且 α、β∈(VT∪VN)*。也就是说，只替换一个非终结符，其余上下文原样保留。

广义推导（p.22）：若存在直接推导序列 α0⇒α1⇒…⇒αn，则称从 α0 可推导出 αn。α0⇒*αn 表示经 0 步或若干步；α0⇒+αn 表示经 1 步或若干步（p.22；文明版 p.53–55 用 i+i*i 的完整序列演示）。

归约（p.26）：若 A→α 是规则，则 xαy ⇒ xAy 是归约。规范推导（最右推导）的逆过程称为最左归约，也称规范归约（文明版 p.70）：N1⇒N⇒ND⇒N2⇒D2⇒12 的规范推导，反向归约就是 12⇒D2⇒N2⇒ND⇒N⇒N1。

素材另给一个较复杂的例子（文明版 p.65–69）：G[S]：S→AB，A→A0 | 1B，B→0 | S1。句子 101001 的最右推导为 S⇒AB⇒AS1⇒AAB1⇒AA01⇒A1B01⇒A1001⇒1B1001⇒101001；最左推导为 S⇒AB⇒1BB⇒10B⇒10S1⇒10AB1⇒101BB1⇒1010B1⇒101001。

递归规则（文明版 p.73–75）：规则 A→A… 为左递归，A→…A 为右递归，A→…A… 为递归；文法层面的递归指存在推导 A⇒+A…（左递归）、A⇒+…A（右递归）或 A⇒+…A…（递归）。递归性使有穷规则能生成无穷语言（见 §2.7）。

2.4　短语、直接短语与句柄

素材位置：第2章 2026.pdf，pp.27、55–56；第2章 2026（文明）.pdf，pp.77–91

关键概念：短语（phrase）、直接短语（simple phrase）与句柄（handle）

一句话定义：在句型 αβδ 中，若 S⇒*αAδ 且 A⇒+β，则 β 是相对非终结符 A 的短语；若 A⇒β 只需一步，则 β 是直接短语；一个句型的最左直接短语称为该句型的句柄。

边界与适用条件：

  • 三个概念都相对于「某个句型」而言，离开句型谈句柄没有意义（p.54 小结）。
  • 短语必须是句型的子串，并且对应语法树中某棵子树的末端结点（文明版 p.88）。
  • 直接短语是某条产生式的右部，对应简单子树的末端结点；句柄还必须最左（p.27；文明版 p.79）。

不是什么：句柄不是「最左短语」，也不是「最右直接短语」。它必须先是直接短语（一步推导），再在所有直接短语中取最左。

表征：

  • 表征一：从定义直接套：G[E]：E→E+T | T，T→T*F | F，F→(E) | i。因 E⇒E+T⇒E+T*F，所以 E+T*F 是句型；短语为 E+T*F、T*F，直接短语为 T*F，句柄为 T*F（p.55）。
  • 表征二：从语法树读：同一棵树上，子树末端给出短语，简单子树末端给出直接短语，最左简单子树给出句柄（下图与文明版 p.88–91）。
  • 表征三：非终结符在中间的句型：G[S]：S→AB，A→Aa | bB，B→a | Sb，句型 baSb（文明版 p.80–91）：短语是 baSb（相对 S）、ba（相对 A）、a（相对第一个 B）、Sb（相对第二个 B）；直接短语 a 与 Sb；句柄 a。

可检验动作：对句型 (A((SaA)(b)))（G[S]：S→(AS) | (b)，A→(SaA) | (a)）从语法树读出短语、直接短语与句柄，并与 p.56 的答案核对。

复现：§2.5 判定二义性时要比较同一句子的两棵树，本质是在比较短语集合；后续语法分析要找「可归约的句柄」，该章素材未提供，未展开。

定义原文（p.27）：设 G[S] 是一个文法，假定 αβδ 是文法 G 的一个句型，如果有 S⇒*αAδ 且 A⇒+β，则称 β 是相对于非终结符 A 的、句型 αβδ 的短语。如果 A⇒β 只需一步，则称 β 是直接短语。一个句型的最左直接短语称为该句型的句柄。

2.5　语法树与文法的二义性

素材位置：第2章 2026.pdf，pp.28–34、57–60；第2章 2026（文明）.pdf，pp.84–105

关键概念：语法树（parse tree）与二义性（ambiguity）

一句话定义：语法树用一个树形图表示句型推导，是不同推导过程的共性抽象；若某个句子存在两棵不同的语法树（或两个不同的最左/最右推导），该文法是二义性的。

边界与适用条件：

  • 文法二义性与语言二义性不同：前者指某个文法有二义句子；后者指不存在任何无二义的文法（p.30）。
  • 二义性问题是不可判定的，只能找「无二义文法」的充分条件（p.31）。
  • 消除办法有两种：不改规则只加非形式语法规定（如 else 就近匹配）；或改写为等价的无二义文法（p.32–34；文明版 p.96–102）。

不是什么：不是「推导步骤多」或「推导序列不唯一」就叫二义——任何句子都可能有多种推导顺序；判定看的是语法树或最左/最右推导是否唯一。

表征：

  • 表征一：两棵树说明二义：G[E]：E→i | E+E | E*E | (E)，句子 i*i+i 可画成 (i*i)+i 与 i*(i+i) 两棵树（文明版 p.94；精简版 p.29 用 (i*i+i) 加括号的版本）。
  • 表征二：改写后唯一：加入「* 优先于 +、同级左结合」后改为 E→E+T | T，T→T*F | F，F→(E) | i，i*i+i 只剩一棵树（p.32、p.98）。
  • 表征三：悬空 else：G：S→if b S | if b S else S | e，句子 if b if b e else e 有两棵树；改写为 S→M | U，M→if b M else M | e，U→if b S | if b M else U 后唯一（p.33–34）。

可检验动作：判断句子 iiiei 在 G[S]：S→iSeS | iS | i 下是否二义，并画出两棵不同的树；再说明为什么改写 G 为 G' 不改变语言。

复现：§2.6 的四型分类与二义性无关（同一语言可既有二义文法又有无二义文法）；§3 的正规文法通常不存在这类表达式优先级问题。

语法树（p.28；文明版 p.84）：对句型的推导过程给出一种图形表示，称语法树或推导树。生成 i*i+i 的两条不同推导，可以画出同一棵树，说明语法树是推导过程的共性抽象。

子树（文明版 p.87–88）：由某一结点连同其所有分枝组成的部分。短语 = 子树末端结点形成的符号串；直接短语 = 简单子树（只有一层分枝）末端结点形成的符号串；句柄 = 最左简单子树的末端符号串。

这棵树对应根按 E→E+E 展开、左子再按 E→E*E 展开，即先乘后加。叶子自左至右是 i * i + i。

二义性的两种消除办法（p.32–34；文明版 p.96–103）：一是不改规则，只加非形式的语法规定（例如「else 与前面最接近的不带 else 的 if 相对应」）；二是构造等价的无二义文法，把优先级与结合规则写进产生式。

先天二义的语言（p.30；文明版 p.105）：L={ aⁱbʲcᵏ | i=j 或 j=k，且 i,j,k≥1 }。一个语言是二义的，指对它不存在无二义文法。注意这与「某个文法二义」是两件事：可以有一个二义文法 G 和一个无二义文法 G'，使 L(G)=L(G')。

素材另给两个判定练习：G[S]：S→iSeS | iS | i 对句子 iiiei 有两棵不同树（p.58）；G[N]：N→SE | E，S→SD | D，E→0|2|4|6|8|10，D→0|…|9 对句子 10 有两棵树，其语言是所有无符号偶数（可带前导 0），改写后 E→0 | 2 | 4 | 6 | 8 即可去二义（p.59–60）。

2.6　乔姆斯基四型文法与语言

素材位置：第2章 2026.pdf，pp.17、35–39；第2章 2026（文明）.pdf，pp.107–117

关键概念：乔姆斯基层级（Chomsky hierarchy）

一句话定义：按产生式的约束强弱把文法分为 0、1、2、3 四型，约束越强描述能力越弱，形成真子集链 L0 ⊇ L1 ⊇ L2 ⊇ L3。

边界与适用条件：

  • 3 型（正规文法）：A→αB 或 A→α（右线性），A→Ba 或 A→α（左线性），α∈VT*。
  • 2 型（上下文无关）：A→β，A∈VN，β∈(VN∪VT)*。
  • 1 型（上下文有关）：αAβ→αμβ，μ∈(VN∪VT)+；等价地 |α|≤|β|，仅 S→ε 例外。
  • 0 型（无限制）：α→β，α∈(VN∪VT)+ 且至少含一个非终结符，β∈(VN∪VT)*。

不是什么：上下文无关不等于上下文有关：CFG 不能生成 aⁿbⁿcⁿ（p.38）。正规文法也不等于「有穷语言」——它可以生成无穷正规语言（如 a*）。

表征：

  • 表征一：层级表：0 型—递归可枚举—图灵机；1 型—上下文有关—线性有界自动机；2 型—上下文无关—非确定下推自动机；3 型—正则—有穷自动机（p.17；文明版 p.28）。
  • 表征二：三个语言的对照：aⁿbⁿ 不能由正规文法产生但可由 CFG S→aSb | ab 产生；aⁿbⁿcⁿ 不能由 CFG 产生，但可由 1 型文法 S→aSBC | aBC、CB→BC、aB→ab、bB→bb、bC→bc、cC→cc 产生（p.38；文明版 p.114）。

可检验动作：判断下列产生式各属哪一型：A→aB；A→a；AB→BA；aB→ab；并说明 aⁿbⁿcⁿ 最低需要哪一型。

复现：§3.2 正规式与 §3.3 正规文法对应 3 型；§3.5 右/左线性文法到有穷自动机的转换，正是 3 型的自动机刻画。

2.7　文法的实用限制、递归性与文法设计

素材位置：第2章 2026.pdf，pp.40、44–49；第2章 2026（文明）.pdf，pp.73–76、118–127

有害规则：形如 A→A 的规则（p.40；文明版 p.118）。它只会让推导空转，不产生任何新串。

多余规则有两类（p.40；文明版 p.118）：某条规则 A→α 的左部 A 不在任何其他规则右部出现（始终用不到，不可用）；或对某非终结符 A，无法从它推出任何终结符号串（不终结）。

化简例（p.40）：G[S]：S→Bd，A→Ad | d | A，B→Cd | Ae，C→Ce，D→e。删去有害规则 A→A、不可用的 D→e 与 A→Ad（A 不出现在任何右部）、不终结的 C→Ce 后，得到 G[S]：S→Bd，A→Ad | d，B→Ae。

递归性与无穷语言（文明版 p.73–76）：若一个不含多余规则的文法是递归的，则它生成语言的句子个数是无穷的（p.76 课堂练习第 2 题答案为 B）。素材还给出一个反例：G[A]：A→aB | bB，B→a | b 无递归性，只能生成 {aa,ab,ba,bb} 四个句子。

设计文法的四要点（p.44；文明版 p.120–121）：(1) 关键是规则集，它精确定义语言结构；(2) 分析已知语言句子的结构特征再写规则，答案不唯一；(3) 文法必须恰好定义该语言，不能超出或缩小；(4) 若语言无穷，文法一定是递归的。

3.2　正规式与正规集

素材位置：第3章 2026.pdf，pp.8–14

关键概念：正规式（regular expression）与正规集（regular set）

一句话定义：正规式由 Φ、ε、单个符号以及「并 |、连接、闭包 *」三种运算构成，用有穷的表达式描述一个正规集（正规语言）。

边界与适用条件：

  • Φ 表示空集，ε 表示只含空串的集合 {ε}；两者不是同一个对象（p.9；文明版 p.14）。
  • 正规式定义中，e1|e2、e1e2、(e1)* 是三条组合规则；优先级与结合性素材未明说，按通常约定 * 最高、连接次之、| 最低（标为推断）。
  • 正规式与正规文法、有穷自动机三者描述能力等价，可相互转换（p.66 小结）。

不是什么：正规式不能描述 aⁿbⁿ 这类需要计数的语言（p.10 提问，p.38 结论），那需要上下文无关文法。正规式也不是「编程语言里的正则字面量」——它是不带语法糖的数学模型。

表征：

  • 表征一：由式读集：Σ={a,b}：a 表示 {a}；a|b 表示 {a,b}；ab 表示 {ab}；(a|b)* 表示所有 a、b 串；ba* 表示 b 后跟任意个 a；(a|b)*(aa|bb)(a|b)* 表示含 aa 或 bb 的串（p.10）。
  • 表征二：由集写式：aa*bb*cc* 表示 { aᵐbⁿcᵏ | m,n,k≥1 }（p.11）；标识符写作 l(l|d)*，整常数写作 dd*（p.12）。
  • 表征三：等价变形：(a|b)* 与 (a*b*)* 等价；b(ab)* 与 (ba)*b 等价（p.13）。八条基本性质见正文。

可检验动作：判断 aab 是否属于 (a|b)*(aa|bb)(a|b)*；再用 p.14 的分配律与 A*=AA*|ε 化简 (a|b)*。

复现：§3.4 的 DFA 识别的正是正规集；§3.3 把正规文法与正规式互转；§3.7 用正规式 l(l|d)* 定义标识符再写成程序。

两种定义方式（p.8）：用正规文法（如 I→l | Il | Id）或正规式（如 l(l|d)*）描述同一类单词。素材以标识符为例并排列出两套规则。

定义（p.9）：Φ 是正规式，表示空集；ε 是正规式，表示 {ε}；对每个 a∈Σ，a 是正规式，表示 {a}；若 e1、e2 是正规式，则 e1|e2、e1e2、(e1)* 也是正规式，分别表示并、连接与闭包。三者反复组合得到的集合就是正规集。

p.10 的例子（Σ={a,b}）：a、a|b、ab、(a|b)*、ba*、(a|b)*(aa|bb)(a|b)* 都给出对应的正规集；并提问「{aⁿbⁿ} 是否正规集」。答案在第 2 章 p.38：aⁿbⁿ 不能由正规文法产生，因此不是正规集。

程序语言单词的正规式（p.12）：关键字 if|else|while|do；标识符 l(l|d)*；整常数 dd*；关系运算符（p.12 的符号在 PDF 中字符挤压成「<<=> >=<>」，无法逐字符确认；p.57 的种别表只列 <=、<>、<，故以 p.57 为准）。

八条基本性质（p.14）：交换律 A|B=B|A、AB≠BA；结合律 (A|B)|C=A|(B|C)、(AB)C=A(BC)；分配律 A(B|C)=AB|AC、(A|B)C=AC|BC；Aε=εA=A；A*=AA*|ε=A|A*=(A|ε)*；(A*)*=A*。

【推断】「* 优先于连接、连接优先于 |」是正规式的通常约定，素材只给了构造规则而未写优先级；本站用它来读 p.10 的式子，标为推断。

3.4　确定有穷自动机 DFA

素材位置：第3章 2026.pdf，pp.23–26

关键概念：确定有穷自动机（DFA）

一句话定义：DFA 是五元组 M=(Q, Σ, f, S, Z)：f 是从 Q×Σ 到 Q 的单值映射，S 是唯一初态，Z 是终态集；从初态出发沿弧上的标记读完整个串，若停在终态则接受该串。

边界与适用条件：

  • 「确定」体现在 f 是单值函数：每个状态对每个输入符号最多只有一条出边（p.24）。

  • 有穷自动机通常用状态转换图表示，它是有穷自动机的非形式化描述（p.65 小结）。

3.5　NFA、ε-闭包与子集法确定化

素材位置：第3章 2026.pdf，pp.27–41

关键概念：非确定有穷自动机（NFA）与子集法（subset construction）

一句话定义：NFA 的转移 f 是多值函数，允许 ε 弧和多个初态；用 ε-闭包把「一个状态集合」当作 DFA 的一个状态，逐步求出新集合，就得到等价的 DFA（子集法）。

边界与适用条件：

  • ε-closure(I)：从 I 中任一状态出发，只经 ε 弧（任意条）可到达的所有状态，连同 I 本身（p.36）。
  • 子集法的两个动作：先求 ε-闭包，再对每个输入符号求「读入后可达集合的 ε-闭包」（p.35–38）。
  • NFA 与 DFA 描述能力等价：每个 NFA 都存在等价 DFA（p.30）。

不是什么：不是「NFA 比 DFA 更强」；也不是「每个 NFA 状态都对应一个 DFA 状态」——子集法是一个子集对应一个状态，可能膨胀。

表征：

  • 表征一：ε-闭包手算：ε-closure({0})={0,1,2,3}；对 A={0,1,2,3}，f(A,b)=f(0,b)∪f(1,b)∪f(2,b)∪f(3,b)={4,7}，再取闭包得 {4,5,6,7,8,9}（p.36–37）。
  • 表征二：子集法表格：把每个状态子集写成一行，对 a、b 分别填目标子集，直到不再出现新子集（p.39 的 (a|b)*abb 例子）。
  • 表征三：分裂法构造 NFA：Thompson 构造：先为 Φ、ε、a 画基本图，再按连接、或、闭包三种复合规则拼装（p.31–33）。

可检验动作：对 (a|b)*abb 的 NFA，先手算 ε-closure({0})，再算出读 b 后的集合，直到得到接受状态包含 Y 的子集。

复现：§3.6 对确定化得到的 DFA 做最小化；§3.7 把最小化 DFA 的每个状态写成一段程序。

NFA 定义（p.27）：N=(Q, Σ, f, S, Z)，其中 f 是 Q×Σ→Q 子集的多值映射（可含 ε 边），S⊆Q 是非空初态集，Z⊆Q 是终态集。

例（p.28）：N=({1,2,3}, {a,b}, f, {1,3}, {2})，f(1,a)={3}，f(1,b)={1,2}，f(2,a)=Φ，f(2,b)={3}，f(3,a)=Φ，f(3,b)={2}，其识别语言为 b*(b|ab)(bb)*。

构造词法分析程序的四步（p.30）：描述单词的正规式或正规文法 → 构造 NFA → 确定化为 DFA → 最小化 DFA → 为每个状态写一小段程序。

分裂法（p.31–33）：引进初态 X 与终态 Y；为 Φ、ε、单个 a 画基本图；再按三种复合规则拼接：连接 r1r2、选择 r1|r2、闭包 r1*。例 (a|b)*abb 与标识符 l(l|d)* 的 NFA 均用此法制出。

3.6　DFA 的最小化

素材位置：第3章 2026.pdf，pp.42–46

关键概念：DFA 最小化（state minimization）与等价状态

一句话定义：先删除不可达的多余状态，再用「一致性」与「蔓延性」两条判定反复分划状态集，把互相等价的状态合并，得到状态数最少、识别语言相同的 DFA。

边界与适用条件：

  • 两个状态等价：对任意输入串，从它们出发要么都到终态，要么都到非终态；否则称为可区别（p.42–43）。
  • 一致性条件：终态与非终态必属于不同的等价类。
  • 蔓延性条件：若两个状态读同一符号后到达的两个状态可区别，则这两个状态也可区别（p.43–44）。
  • 分划法：初始按「终态 / 非终态」分划，反复按蔓延性细分，直到每个子集内部不可再分（p.44）。

不是什么：最小化不改变语言，也不改变确定性；它不是简单删掉重复状态，而是合并等价状态并重定向所有转移。

表征：

  • 表征一：分划过程：初始 ∏=({A,B,C,D},{E})，A、B、C、D 读 0/1 的去向不同，再分为 ({A,C},{B},{D},{E})（p.45）。
  • 表征二：另一个例子：初始 ({1,2},{0})，按转移细分后得到最小 DFA（p.46）。

可检验动作：对 p.45 的例子手算两层分划：先写「读 0 / 读 1 到哪个类」，再判断 A 与 C 是否还能区分。

复现：§3.7 中状态转换图的状态数就是最小化后的 DFA 状态数，状态越少代码段越少。

化简的两步（p.42）：先删去不可达的状态（从初态出发永远到不了），再合并等价状态。

等价与可区别（p.42–43）：设 s、t 为两个状态，若对任意输入串 ω，从 s 出发读 ω 停在终态当且仅当从 t 出发读 ω 停在终态，则 s 与 t 等价；否则可区别。

一致性条件（p.43）：终态与非终态是可区别的，必须分属不同的等价类。蔓延性条件（p.44）：若 s、t 读同一符号 a 后到达 s'、t'，且 s'、t' 可区别，则 s、t 也可区别。

分划法步骤（p.44）：① 把状态分为终态组与非终态组；② 对每个组，检查组内状态读同一符号后是否落入同一组，若不同则按去向再分；③ 重复直到每个组不能再分；④ 每个组取一个代表状态，重定向转移。例 1（p.45）：∏=({A,B,C,D},{E})，A、B、C、D 读 0 后分别到 B、B、C、C，读 1 后分别到 C、D、C、E，故再分为 ({A,C},{B},{D},{E})。

素材另给例 2（p.46）：初始分划 ({1,2},{0})，按读 0、读 1 的去向细分后得到最小 DFA，并在 p.66 小结中强调「两正规式等价 ⟺ 它们的最小状态 DFA 相同」。

        default: error( );  break;
    }
}

逐段讲解（代码 3-3）：单字符运算符直接返回种别码。< 与 : 需要向前看一个字符：若紧跟 = 就返回双字符运算符（17 为 <=、22 为 :=），若 < 后紧跟 > 则返回 18（<>）；否则 retract 回退并按单字符返回（19 为 <、21 为 :）。default 落到 error()，对应状态图中的出错状态 17。

【素材未展开 / 需注意】① 代码中的 getch、getbc、concat、reserve、retract、dtb、error 只有文字说明，没有函数体；② 关键字表的内容与查表算法未给出；③ switch 中没有 > 与 >= 的分支，与 p.57 种别表一致，但与 p.12 的关系运算符列表不一致；④ 代码未处理空白结束后的文件结束符。以上均按素材现状呈现，不补写实现。

小结（p.65–66）：正规式、正规文法、有穷自动机三者描述能力等价、可相互转换；转换链为 正规式 --分裂法--> NFA --子集法--> DFA --分划法--> 最小化 DFA --每状态一段程序--> 词法分析程序。证明两个正规式等价，可比较它们的最小状态 DFA 是否相同。

string		由字母表中符号构成的有穷序列。空符号串 ε 也是符号串，长度 0；ε 与空集 Φ 完全不同。第2章 p.9；文明版 p.10–14

closure		A* = A0∪A1∪…（含 ε），A+ = A1∪A2∪…（不含 ε）。A0={ε}，不是 {1}；A*={ε}∪A+。第2章 p.11；文明版 p.19–20

grammar		上下文无关文法是四元组 G=(VT,VN,S,P)，用有穷产生式描述语言的语法结构。同一语言可对应多个文法（语言→文法不唯一）；文法→语言唯一确定。第2章 p.19；文明版 p.33、p.63
产生式（规则）
production		形如 A→β 的有序对，表示可用 β 替换非终结符 A。A→β 与 A::=β 同义；一行多个候选式用 | 缩写。第2章 p.18、p.21
终结符 / 非终结符
terminal / nonterminal		终结符 VT 是语言最终串里的符号；非终结符 VN 是推导过程中可被替换的语法变量。VT∩VN=∅；开始符号 S 属于 VN。第2章 p.19
推导
derivation		用产生式把句型中的非终结符替换成右部，得到新句型。⇒ 是一步，⇒* 是 0 步或更多步，⇒+ 是 1 步或更多步。第2章 p.22

reduction		推导的逆过程：把句型中的某产生式右部替换回左部非终结符。与推导方向相反；最右推导的逆过程叫最左归约/规范归约。第2章 p.26；文明版 p.70
最左推导 / 最右（规范）推导
leftmost / rightmost derivation		每步都替换最左非终结符（最左推导）或最右非终结符（最右推导）。普通推导序列通常不唯一，不能用来判定二义性；只有最左/最右推导唯一性可以。第2章 p.25；文明版 p.95
句型 / 句子
sentential form / sentence		S⇒*α 的 α 是句型；只含终结符的句型是句子。句子一定是句型，句型不一定只含终结符。第2章 p.23
短语 / 直接短语 / 句柄
phrase / simple phrase / handle		若 S⇒*αAδ 且 A⇒+β，β 是相对 A 的短语；A⇒β 一步完成则为直接短语；最左直接短语是句柄。三者都相对某个句型而言；句柄必先是直接短语，再取最左。第2章 p.27、p.55
语法树
parse tree		用一个树形图表示句型的推导，是不同推导过程的共性抽象。子树末端形成短语，简单子树末端形成直接短语。第2章 p.28；文明版 p.84–88
二义性
ambiguity		某句子存在两棵不同语法树（或两个不同最左/最右推导）时，该文法是二义的。文法二义性与语言二义性不同；后者指不存在任何无二义文法。第2章 p.29–31
乔姆斯基层级
Chomsky hierarchy		按产生式限制把文法分为 0/1/2/3 型，描述能力 L0 ⊇ L1 ⊇ L2 ⊇ L3。上下文无关（2 型）比上下文有关（1 型）弱；正规（3 型）最弱。第2章 p.17、p.35–39
正规文法（3 型）
regular grammar		产生式形如 A→aB 或 A→a（右线性），或 A→Ba 或 A→a（左线性），a∈VT*。正规文法只能生成正规语言；a^n b^n 需要上下文无关文法。第2章 p.37；文明版 p.108
正规式
regular expression		由 Φ、ε、单符号及 |、连接、* 三种运算构成的有穷表达式，用来描述正规集。Φ 表示空集，ε 表示只含空串的集合；正规式与正规文法、有穷自动机等价。第3章 p.9；文明版 p.14
确定有穷自动机
DFA		五元组 (Q,Σ,f,S,Z)，f 是单值映射，S 唯一初态，沿标记路径读完整串到终态即识别。与 NFA 的差别在 f 单值/多值、初态唯一/集合、是否允许 ε 边。第3章 p.24
非确定有穷自动机
NFA		f 为多值映射且允许 ε 边、可有非空初态集的自动机。NFA 描述能力不比 DFA 强：每个 NFA 都存在等价 DFA。第3章 p.27、p.30
ε-闭包
ε-closure		状态集 I 经任意条 ε 弧可到达的状态集合（含 I 自身）。只走 ε 边，不读输入符号。第3章 p.36
子集法
subset construction		把 NFA 的状态子集作为一个 DFA 状态，逐步求出转移，得到等价 DFA。与「分裂法」（正规式→NFA）方向相反，子集法是 NFA→DFA。第3章 p.35–38
状态最小化
state minimization		用一致性条件与蔓延性条件反复分划状态集，合并等价状态，得到状态最少的等价 DFA。先删不可达的多余状态；最小化不改变语言。第3章 p.42–44
交叉编译
cross compiler		在一种机器上运行、却为另一种机器生成目标代码的编译器。与自举不同：自举是用语言自身编译自身。第1章 p.45
自举
bootstrapping		用语言提供的功能来编译该语言自身，常通过不断扩充语言子集实现。Pascal 例子是逐级自举，不是交叉编译。第1章 p.46
