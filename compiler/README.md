## 目录结构

```
learn-site/
├── index.html            入口页（只负责呈现）
├── backup.html           无脚本纯文本备份，含全部正文、答案与解析
├── assets/
│   ├── app.css           样式（深浅色、响应式、打印）
│   └── app.js            渲染、检索、自测判分、两个演示
├── content/
│   ├── meta.json         站点元信息与术语表
│   ├── ch1.json          第 1 章内容源
│   ├── ch2.json          第 2 章内容源
│   ├── ch3.json          第 3 章内容源
│   └── course.js         由上述 JSON 合并生成，供 file:// 直接加载
├── concepts.md           关键概念清单（编制依据，与正文分离）
└── README.md             本文件
```

## 维护方式

1. 改内容：编辑 `content/meta.json`、`content/ch1.json`、`content/ch2.json`、`content/ch3.json`；正文、题目、术语表都在这四个文件里，不要直接改 `content/course.js` 或 `backup.html`。
2. 重新生成：运行同目录构建脚本（Python 3 标准库即可）：

   ```
   python build.py
   ```

   脚本会做结构与配置校验（id 唯一、答案下标不越界、多选答案数量一致、关键概念字段齐全、演示引用的表格存在），然后合并出 `content/course.js`、生成 `backup.html`，并同步到交付目录。
3. 改样式或交互：编辑 `assets/app.css`、`assets/app.js`，无需重新生成内容。
4. 新增章节：在对应 `chN.json` 增加 `sections` 项，并在 `meta.json` 的术语表补上该节新术语，然后重跑构建。
