- 版本：v1.0｜日期：2026-11-06

- 风格基准：**当前** `D:\gpt\www\compiler`（含 11-05 晚的优化补丁）与 `D:\gpt\www\_shared` 共享层。目录名、文件名、页面 ID、`data-w1-site` 属性命名、导航逻辑与数据格式保持一致；共享层三个文件按同名复制到 `assets/`，因此本站脱离 www 目录也能完整呈现。

## 三、内容与教学设计

- **由浅入深**：1.1–1.4 建立「是什么 / 做什么 / 怎么评价」，1.5–1.7 讲演化与结构；2.1–2.3 铺垫硬件，2.4–2.7 进入中断、BIOS、启动与生成三个重点。
- **核心概念**：9 个关键概念走「命名 → 定义 → 边界 → 不是什么 → 两种表征 → 可检验动作 → 复现」处理链，判定标准与密度约束见 `concepts.md`。
- **运行流程 / 关键模块**：12 张流程示意覆盖三层次结构、fprintf 调用链、四大功能映射、系统层次、四阶段作业流、三种内核结构、CPU 内部与态转换、存储体系、中断过程、BIOS 自举、Linux 启动链与登录链、内核生成。
- **常见操作场景**：p.34 的七个追问逐条映射到 OS 功能；INT 13H 读扇区、Linux 登录、内核编译等给出可对照的参数表与命令。
- **易错点**：每节的 `note k-tip` 明确列出混淆项（并发 vs 并行、断点 vs 现场、设备无关性 vs 文件抽象、吞吐率 vs 响应能力、启动 vs 生成、宏内核 vs 微内核等）。
- **自测**：节内自测 + 章末综合自测共 47 题，含单选与多选，即时判分、可重做，解析回指具体小节与表格。课件里只给题目未给答案的 p.39、p.77、p.107 已补齐解析并标注「推断」。
- **事实与不确定性**：只使用 PDF 可读文本层；乱码页、截图页、缺失实现均在页面「素材边界／内容边界」中标注「素材未提供／待核实」，不用常识补写。p.12 列出的课程第 3–10 章课件未提供，明确登记为未覆盖，不补编。

## 五、使用与维护

1. **阅读**：双击 `index.html`；顶部检索可查章节、表格与术语；左侧目录与正文一一对应；右下「打印」可输出 PDF。脚本禁用时打开 `backup.html`。
2. **改内容**：只编辑 `content/meta.json`、`content/ch1.json`、`content/ch2.json`，然后在本目录运行 `python build.py`。脚本会校验 id 唯一、答案下标与多选数量、关键概念字段、演示引用的表格、表格列数、素材位置，再重新生成 `course.js` 与 `backup.html`；校验不通过则**不写任何产物**。
3. **改样式/交互**：编辑 `assets/app.css` / `assets/app.js`；无需重跑构建。
4. **新增章节**：新建 `content/chN.json`（字段与 ch1/ch2 一致），把它加入 `build.py` 的 `CHAPTER_FILES`，并同步 `meta.json` 的术语表与 `scope.covers`。
5. **新增步进演示**：给表格块加 `id`，在小节加 `demo: {"type":"pipeline","table":"该 id","label":"…"}`，无需改 `app.js`。
